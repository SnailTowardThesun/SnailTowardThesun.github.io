> 括号嵌套深度是解析器的核心概念，代码编辑器的自动缩进就是靠跟踪深度实现的。

## 题目

LeetCode 1021. Remove Outermost Parentheses（删除最外层的括号）

Difficulty: **Easy**

有效括号字符串为空 `""`、`"(" + A + ")"` 或 `A + B`，其中 `A` 和 `B` 都是有效括号字符串。

原始字符串（primitive）是一个非空的有效括号字符串，且它不能分割为两个非空有效括号字符串的连接。

给定一个有效括号字符串 `s`，考虑它的原始分解：`s = P_1 + P_2 + ... + P_k`，其中 `P_i` 是原始字符串。返回删除 `s` 中每个原始字符串**最外层括号**后的结果字符串。

### 示例

```
输入：s = "(()())(())"
输出："()()()"
解释：原始分解为 "(()())" + "(())"，
删除最外层括号后为 "()()" + "()" = "()()()"。

输入：s = "(()())(())(()(()))"
输出："()()()()(())"

输入：s = ""
输出：""
```

## 解题思路

### 栈跟踪嵌套深度

最外层括号的判定标准很简单：**栈空（深度为 0）时遇到的 `'('` 和把它弹空的那个 `')'`** 就是原始字符串的外壳。

用一个栈（本题只需 `stack<char>`，其实用深度计数也可以）跟踪当前状态：

1. **`'('`**：先判断——若栈非空，说明它不是最外层，追加到结果；然后入栈；
2. **`')'`**：先弹栈与栈顶 `'('` 匹配；若弹栈后栈仍非空，说明它不是最外层，追加到结果。

这样最外层的括号在"入栈前"和"弹空后"两个时机都被自然跳过，剩余字符全部保留。

以 `"(()())(())"` 为例：第 1 个 `(` 时栈空，跳过；中间的字符栈非空，全部保留；第 6 个 `)` 弹空栈，跳过。第二个原始串同理，最终得到 `"()()()"`。

### 复杂度分析

- **时间复杂度**：O(n)，每个字符处理一次。
- **空间复杂度**：O(n)，用于栈和结果字符串。

## 代码实现

```cpp
class Solution {
   public:
    string removeOuterParentheses(string s) {
        string ret;
        stack<char> container;
        for (auto ch : s) {
            if (ch == '(') {
                if (!container.empty()) {
                    ret += ch;
                }
                container.emplace(ch);
            } else {
                if (container.top() == '(') {
                    container.pop();
                }
                if (!container.empty()) {
                    ret += ch;
                }
            }
        }

        return ret;
    }
};
```

### 代码解析

- **两个判断时机**：`'('` 在入栈**前**判断（栈非空才保留），`')'` 在弹栈**后**判断（栈非空才保留），正好把外壳的左右括号都过滤掉。
- **栈的实际用途**：因为输入保证是有效括号串，栈里永远只有 `'('`，所以用 `int depth` 计数器可以完全替代，空间可优化到 O(1)（不含结果串）。
- **保留原始逻辑**：当前实现清晰表达了"深度"这一概念，可读性好。

## 测试用例

```cpp
TEST(Daily, 1021) {
    Solution s;
    // 两个原始串
    EXPECT_EQ(s.removeOuterParentheses("(()())(())"), "()()()");
    // 含嵌套的原始串
    EXPECT_EQ(s.removeOuterParentheses("(()())(())(()(()))"), "()()()()(())");
    // 空串
    EXPECT_EQ(s.removeOuterParentheses(""), "");
    // 单个原始串
    EXPECT_EQ(s.removeOuterParentheses("()()"), "()()");
}
```

## 总结

1. 最外层括号 = 栈空时的 `'('` 和弹空栈的 `')'`；
2. `'('` 入栈前判断、`')'` 弹栈后判断，两个时机过滤外壳；
3. 输入保证有效，栈可退化为深度计数，O(n) 时间。
