> 括号匹配是栈的经典应用：编译器语法分析、编辑器括号高亮与自动补全，背后都是类似的匹配思想。

## 题目

LeetCode 32. Longest Valid Parentheses（最长有效括号）

Difficulty: **Hard**

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

### 示例

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"

输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"

输入：s = ""
输出：0
```

## 解题思路

### 下标栈一次遍历

暴力枚举所有子串再逐一校验是 O(n³)，必然超时。换个角度：**有效括号串一定以右括号结尾**，所以扫描时每遇到一个 `)`，直接算出“以它结尾的最长有效串长度”即可。

栈中存下标而不是字符，并维护一个关键不变式：**栈底始终是“最后一个未被匹配的右括号”的下标**，它是有效区间无法跨越的断点；断点之上是尚未匹配的左括号下标。

1. 初始压入 `-1`，充当“位置 0 前面的虚拟断点”，方便统一长度计算；
2. 遇到 `'('`：下标压栈，等待匹配；
3. 遇到 `')'`：先弹出栈顶尝试配对：
   - 弹完后栈为空：说明该右括号没有左括号可配，它自己成为新断点，压入栈中；
   - 弹完后栈非空：配对成功，当前位置与栈顶之间恰好是一段完整合法的序列，长度为 `i - 栈顶下标`，更新答案。

以 `")()())"` 为例：i=2 配对后栈顶为 0，长度 2-0=2；i=4 配对后栈顶仍为 0，长度 4-0=4；末尾的 `)` 弹空栈后成为新断点。最终答案为 4。

### 复杂度分析

- **时间复杂度**：O(n)，每个下标至多入栈、出栈各一次。
- **空间复杂度**：O(n)，最坏情况（全为左括号）栈中保存全部下标。

## 代码实现

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int ret = 0;

        stack<int> stk;
        stk.emplace(-1);
        for (auto i = 0; i < s.size(); ++i) {
            if (s.at(i) == '(') {
                stk.emplace(i);
            } else {
                stk.pop();
                if (stk.empty()) {
                    stk.emplace(i);
                } else {
                    ret = max(ret, i - stk.top());
                }
            }
        }

        return ret;
    }
};
```

### 代码解析

- **初始的 -1 是精髓**：串从下标 0 开始合法时（如 `"()"`），`1 - (-1) = 2` 才能算出正确长度。
- **弹空后压入当前下标**：保证栈底永远是最近一个多余右括号，任何有效串都不会错误地跨过它。
- 本题还有 DP（`dp[i]` 表示以 i 结尾的最长有效串长度）和双向计数（空间 O(1)）两种解法，时间复杂度同为 O(n)。

## 测试用例

```cpp
TEST(Daily, 32) {
    Solution s;
    // 基本用例：一对括号
    EXPECT_EQ(s.longestValidParentheses("()"), 2);
    // 嵌套：部分匹配
    EXPECT_EQ(s.longestValidParentheses("(()"), 2);
    // 右括号开头，中间存在有效串
    EXPECT_EQ(s.longestValidParentheses(")()())"), 4);
    // 边界：空串
    EXPECT_EQ(s.longestValidParentheses(""), 0);
    // 边界：全部无法匹配
    EXPECT_EQ(s.longestValidParentheses("((("), 0);
}
```

## 总结

1. 下标栈栈底存“最后一个未匹配右括号”作为断点，初始压入 -1；
2. 遇右括号弹栈：栈空则当前位置成为新断点，否则长度为 `i - 栈顶`；
3. 一次扫描完成，O(n) 时间、O(n) 空间，取代超时的 O(n³) 暴力枚举。
