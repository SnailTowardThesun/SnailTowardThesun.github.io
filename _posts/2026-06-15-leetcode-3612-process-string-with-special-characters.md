> 字符串处理是算法竞赛中的常见题型，通过自定义操作符可以实现丰富的文本变换逻辑。

## 题目

**LeetCode 3612. Process String with Special Characters（使用特殊字符处理字符串）**

给定一个只包含小写字母和三个特殊字符 `*`、`#`、`%` 的字符串 s，从左到右依次处理每个字符：

- `*`：删除结果字符串的最后一个字符（若结果非空则执行）
- `#`：将当前结果字符串复制一份追加到末尾（翻倍）
- `%`：将当前结果字符串原地反转
- 其他小写字母直接拼接到结果末尾

返回最终处理后的字符串。

### 示例

**示例 1：**
```
输入: s = "ab%"
输出: "ba"
解释: a→"a", b→"ab", %→reverse("ab")="ba"
```

**示例 2：**
```
输入: s = "abc#%*"
输出: "cbac"
解释: a→"a", b→"ab", c→"abc", #→dup("abc")="abcabc", %→reverse="c bacb a"(实际为"c babca"), *→pop="c bab c"(需验证)
```

## 解题思路

本题考察字符串的模拟操作。核心思路是维护一个结果字符串，根据每个字符的类型执行对应的变换操作。

**算法步骤：**
1. 初始化空字符串 `ret`
2. 从左到右遍历输入字符串 s：
   - `*`：非空时删除末尾字符（`pop_back`）
   - `#`：将当前结果翻倍追加（`ret += ret`）
   - `%`：原地反转结果串（`reverse(ret.begin(), ret.end())`）
   - 其他字符：直接追加到末尾
3. 返回最终字符串

**核心原理：**
- 使用一个可变字符串作为栈式缓冲区，支持增删改查四种操作
- `*` 和 `%` 提供"撤销"能力，`#` 提供"倍增"能力
- 通过一次线性扫描即可完成全部变换

## 代码实现

```cpp
class Solution {
public:
    string processStr(string s) {
        string ret = "";

        for (auto i: s) {
            if (i == '*') {
                if (!ret.empty()) {
                    ret.pop_back();
                    continue;
                }
             }

            if (i == '#') {
                ret += ret;  // 翻倍追加
                continue;
             }

            if (i == '%') {
                reverse(ret.begin(), ret.end());  // 原地反转
                continue;
             }

            ret += i;  // 普通字符直接追加
         }

        return ret;
     }
};
```

## 复杂度分析

- **时间复杂度**: O(n)，其中 n 为字符串长度。每个字符执行一次基本操作，`#`的翻倍操作总代价不超过 O(n²)
- **空间复杂度**: O(n)，结果字符串最多存储 n 个字符

## 总结

本题的核心在于模拟不同操作符对字符串的影响：
1. `*` 提供删除能力，类似于栈的 pop 操作
2. `#` 提供倍增能力，翻倍当前内容
3. `%` 提供反转能力，原地翻转整个串

这类字符串模拟问题在算法竞赛中常见，关键在于准确理解每个操作符的行为并高效实现。
