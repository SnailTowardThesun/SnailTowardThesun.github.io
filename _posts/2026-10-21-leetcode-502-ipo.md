> 这是 LeetCode 少有的以「IPO」命名的题：投资能力随收益滚动增长，「买得起的项目集合只会扩张」这一单调性，正是把每轮全量扫描优化为指针只进不退的关键。

## 题目

LeetCode 502. IPO

Difficulty: **Hard**

假设 LeetCode 即将开始 IPO。为了以更高的价格将股票卖给投资公司，LeetCode 希望在 IPO 之前开展一些项目以增加其资本。由于资源有限，它只能在 IPO 之前完成**最多 `k` 个**不同的项目。

给你 `n` 个项目：对每个项目 `i`，它都有纯利润 `profits[i]`，和启动该项目所需的**最小资本** `capital[i]`。

最初你的资本为 `w`。完成一个项目时，你将获得纯利润并加到总资本中。从给定项目中选择最多 `k` 个不同项目，**最大化最终资本**，并输出最终可获取的最大资本。

### 示例

```
输入：k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
输出：4
解释：第 1 轮资本 0，只能做项目 0，资本变 1；第 2 轮可选项目 1/2，
     做利润最高的项目 2，资本变 4。

输入：k = 3, w = 0, profits = [1,2,3], capital = [0,1,2]
输出：6
```

## 解题思路

### 贪心策略

每轮在「买得起」（`capital <= w`）的项目里选利润最高的。由于 `profits[i] >= 1`，做项目必不亏，这个贪心是安全的。

### 性能关键：每个项目只处理一次

直接模拟会超时：每轮重建堆找最大、再从原数组删除元素，单轮 `O(n)`，k 轮共 `O(k*n*log n)`，本题 `n`、`k` 都可达 `10^5`。

利用一个单调性——**w 只增不减，买得起的集合只会扩张**：

1. 项目按启动资本升序排序，维护指针 `idx` 指向下一个未入堆的项目；
2. 每轮先把所有 `capital <= w` 的项目入堆（指针永不回退，每个项目一生只入堆一次），堆存取负的利润模拟最大堆；
3. 弹堆顶（当前最大利润）累加到 `w`；堆空说明无项目可做，提前结束。

### 复杂度分析

| 解法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 每轮全量扫描 | `O(k*n*log n)` | `O(n)` |
| 排序 + 增量入堆 | `O(n*log n + k*log n)` | `O(n)` |

## 代码实现

```python
import heapq


class Solution:
    def findMaximizedCapital(self, k: int, w: int, profits: list[int], capital: list[int]) -> int:
        projects = sorted(zip(capital, profits, strict=True))
        idx = 0
        container = []
        for _ in range(k):
            while idx < len(projects) and projects[idx][0] <= w:
                heapq.heappush(container, -projects[idx][1])
                idx += 1

            if len(container) == 0:
                continue

            w = w - heapq.heappop(container)

        return w
```

### 代码解析

- **排序一次，指针只进不退**：`w` 单调递增使得「入堆门槛」只降不升，排序后每个项目至多被检查一次、入堆一次；
- **取负模拟最大堆**：`heapq` 只有最小堆，存 `-profits` 后堆顶就是最大利润，`w - heappop(...)` 即加上原利润；
- **堆空提前结束**：无项目可做且以后也不会有（`w` 不再增长），继续循环只是空转；
- **不需要删除项目**：入堆即「注册」，弹出即「完成」，天然保证每个项目至多做一次。

## 测试用例

```python
def test_find_maximized_capital():
    s = Solution()
    assert s.findMaximizedCapital(2, 0, [1, 2, 3], [0, 1, 1]) == 4
    assert s.findMaximizedCapital(3, 0, [1, 2, 3], [0, 1, 2]) == 6
    assert s.findMaximizedCapital(1, 5, [10], [100]) == 5  # 一个都做不了
    assert s.findMaximizedCapital(10, 0, [1], [0]) == 1  # k 远大于项目数
```

## 总结

- 贪心正确性来自 `profits >= 1`：每轮选买得起的最大利润项目必不亏；
- 「w 单调增 → 候选集合只扩张」是消灭每轮全量扫描的关键，排序 + 指针让每个项目只入堆一次；
- 与 215、373 同属一个套路：**不物化候选全集，用有界堆做增量维护**。
