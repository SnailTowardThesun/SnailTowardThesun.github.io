> 递归下降与栈式求值是表达式计算的两大经典思路，编译器、电子表格、SQL 解析器中都能看到它们的身影。

## 题目

LeetCode 224. Basic Calculator（基本计算器）

Difficulty: **Hard**

给你一个字符串表达式 `s`，请你实现一个基本计算器来计算并返回它的值。

- `s` 由数字、`'+'`、`'-'`、`'('`、`')'` 和空格 `' '` 组成；
- 输入表达式始终有效，只有加减法，允许括号嵌套；
- 所有整数均为非负数，结果保证是一个 32 位有符号整数。

### 示例

```
输入：s = "1 + 1"
输出：2

输入：s = " 2-1 + 2 "
输出：3

输入：s = "(1+(4+5+2)-3)+(6+8)"
输出：23
```

## 解题思路

### 一次遍历 + 栈保存括号外上下文

表达式里只有加减，难点只在**括号嵌套**。括号的作用是“把括号内当成一个整体，带着括号前的符号并入外层”。我们可以在进入括号时把外层状态压栈保存，出括号时再取回归并。

维护三个变量：

- `ret`：当前这一层已经结算的结果；
- `num`：正在读取的多位数；
- `pre`：当前数字前面的符号，`+1` 表示加、`-1` 表示减。

逐个字符处理：

1. **数字**：`num = num * 10 + digit`，拼出多位数；
2. **`'+'` / `'-'`**：先把 `pre * num` 结算进 `ret`，再重置 `num`、更新 `pre`；
3. **`'('`**：把当前层的 `ret` 和 `pre` 依次压栈，然后重置为括号内的新一层（`ret = 0, pre = 1`）；
4. **`')'`**：先结算括号内最后一个数字，再把括号内结果乘上栈中保存的外层符号、加上栈中保存的外层结果，完成一层归并；
5. **空格**：直接忽略。

循环结束后表达式可能不以括号结尾，最后一个数字还没结算，返回 `ret + pre * num`。

以 `"2-(5-6)"` 为例：遇到 `(` 时压入 `2` 和 `-1`；括号内算出 `5-6 = -1`；遇 `)` 时 `-1 × (-1) + 2 = 3`。

### 复杂度分析

- **时间复杂度**：O(n)，每个字符只处理一次。
- **空间复杂度**：O(n)，栈深度等于括号嵌套层数。

## 代码实现

```cpp
class Solution {
   public:
    int calculate(string s) {
        long ret = 0;
        long num = 0;
        long pre = 1;  // 1 for plus, -1 for minus
        stack<long> stk;

        for (auto c : s) {
            if (c >= '0' && c <= '9') {
                num = num * 10 + c - '0';
            } else if (c == '+') {
                ret += pre * num;
                num = 0;
                pre = 1;
            } else if (c == '-') {
                ret += pre * num;
                num = 0;
                pre = -1;
            } else if (c == '(') {
                stk.push(ret);
                stk.push(pre);
                ret = 0;
                pre = 1;
            } else if (c == ')') {
                ret += num * pre;
                num = 0;
                ret *= stk.top();
                stk.pop();
                ret += stk.top();
                stk.pop();
            }
        }

        return static_cast<int>(ret + pre * num);
    }
};
```

### 代码解析

- **栈里成对压入「外层结果、外层符号」**：出括号时先弹符号、再弹结果，顺序不能反。
- **用 `pre` 把减法统一成加法**：每个数字只关心自己前面的符号，括号内整体结果也通过乘符号归并，逻辑高度统一。
- 中间值用 `long` 存储，避免中间过程（如取反、累加）触及 int 边界；题目保证最终结果在 32 位范围内。

## 测试用例

```cpp
TEST(top150, 224) {
    Solution s;
    // 基本加减
    EXPECT_EQ(s.calculate("1 + 1"), 2);
    // 带空格
    EXPECT_EQ(s.calculate(" 2-1 + 2 "), 3);
    // 括号嵌套
    EXPECT_EQ(s.calculate("(1+(4+5+2)-3)+(6+8)"), 23);
    // 边界：单个数字
    EXPECT_EQ(s.calculate("2147483647"), 2147483647);
    // 边界：括号前为负号，括号内整体取反
    EXPECT_EQ(s.calculate("2-(5-6)"), 3);
}
```

## 总结

1. 只有加减的表达式，核心难点是括号：进括号压栈保存外层结果与符号，出括号归并；
2. `pre` 记录当前数字前的符号，把减法统一为带符号的加法；
3. 末尾补上 `ret + pre * num`，O(n) 时间、O(n) 空间。
