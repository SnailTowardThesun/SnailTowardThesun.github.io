> 「恰好等于 k 的按位与」是道单向门：一次交换不改变「值与 k 的公共 1 位」，所以错位元素缺少的位永远带不进任何交换——全体错位值的按位与，就是能放行的最大 k。

## 题目

LeetCode 3644. Maximum K to Sort a Permutation（排序排列）

Difficulty: **Medium**

给你一个长度为 `n` 的整数数组 `nums`，其中 `nums` 是范围 `[0..n-1]` 内所有数字的一个**排列**。

你可以在满足条件 `nums[i] AND nums[j] == k` 的情况下交换下标 `i` 和 `j` 的元素，其中 `AND` 表示按位与操作，`k` 是一个**非负整数**。

返回可以使数组按**非递减**顺序排序的最大值 `k`（允许进行任意次这样的交换）。如果 `nums` 已经是有序的，返回 `0`。

### 示例

```
输入：nums = [0,3,2,1]
输出：1
解释：k=1 时交换 nums[1]=3 和 nums[3]=1（3 AND 1 == 1），得到 [0,1,2,3]。

输入：nums = [0,1,3,2]
输出：2
解释：k=2 时交换 nums[2]=3 和 nums[3]=2（3 AND 2 == 2）。

输入：nums = [3,2,1,0]
输出：0
```

## 解题思路

### 先排除一个直觉错误

「答案 = 每个错位环各自可行的最大 k 再取 max」是错的。反例：`[0,1,3,2,6,5,4,7]` 有两个错位环——`{3,2}` 用 `k=2` 可排，`{6,4}` 用 `k=4` 可排——但真实答案是 `0`：没有任何**单一** `k` 能同时排好两个环，即使允许借助中间元素倒手。答案由全体错位元素**共同**决定。

### 为什么是「错位值的按位与」

合法交换要求两个值 `AND` **恰好等于** `k`，等价于两个值都含有 `k` 的全部 `1` 位且不在别处重叠出更多的公共 1 位。关键的单向性在于：

- 要让某个错位值挪走，参与交换的另一方必须与它有足够的公共位；
- 某个错位值缺少的位，任何包含它的交换都无法通过 `AND == k` 的校验把它「补」上。

于是最大可行 `k` 就是**所有错位值（`nums[i] != i`）的按位与**：

1. `ret` 初始化为 `-1`（二进制全 1，与运算的幺元），逐个与错位值相与；
2. 若全部在位，`ret` 保持 `-1`，按题意返回 `0`。

错位值里只要有一个含 `0`（如 `[1,0]`），与结果立刻归零——`k=0` 总是安全的兜底（`AND == 0` 的交换对始终存在）。

### 复杂度分析

一次线性扫描，时间 `O(n)`，空间 `O(1)`。

## 代码实现

```python
class Solution:
    def sortPermutation(self, nums: list[int]) -> int:
        ret = -1
        for i in range(len(nums)):
            if nums[i] == i:
                continue
            ret &= nums[i]
        return 0 if ret == -1 else ret
```

### 代码解析

- **`-1` 是全 1 幺元**：`-1 & x == x`，起步不影响第一位错位值；
- **在位即跳过**：`nums[i] == i` 的元素不需要参与任何交换，不参与与运算；
- **有序特判合并进返回值**：全在位时 `ret` 仍是 `-1`，条件表达式直接映射为题目要求的 `0`。

## 测试用例

```python
s = Solution()
assert s.sortPermutation([0, 3, 2, 1]) == 1   # 官方示例 1
assert s.sortPermutation([0, 1, 3, 2]) == 2   # 官方示例 2
assert s.sortPermutation([3, 2, 1, 0]) == 0   # 官方示例 3
assert s.sortPermutation([0, 1, 2, 3]) == 0   # 已有序特判
assert s.sortPermutation([1, 0]) == 0         # 错位值含 0
assert s.sortPermutation([0, 1, 2, 3, 4, 5, 7, 6]) == 6  # 错位 {7,6}
```

另做了 200 组随机排列（`n <= 6`）与状态空间 BFS 的对拍：固定每个 `k`，在真实交换状态空间里搜「有序态」可达性，`k` 从高到低取第一个可行的作为真值——公式解与真值逐组一致。之所以用完整状态空间而非手推，是因为交换可以借助中间元素倒手，可达性靠脑补很容易漏。

## 总结

- `AND == k` 的交换有单向性：缺的位永远进不来，所以最大 `k` = 错位值的按位与；
- 答案由全体错位元素共同决定，逐环取最大是典型误区（双环反例答案归 0）；
- 可达性类问题用状态空间 BFS 当真值做对拍，比任何手推都可靠。
