> 逆向思维是算法设计中的利器：当正向构建代价过高时，从目标位置逆向回溯往往能将指数级问题降为线性。

## 题目

**LeetCode 3614. Process String with Special Operations II（用特殊操作处理字符串 II）**

难度：困难

给定一个只包含小写字母和三个特殊字符 `*`、`#`、`%` 的字符串 s，以及一个整数 k。从左到右依次处理每个字符：

- 小写字母：拼接到结果末尾
- `*`：删除结果字符串的最后一个字符（若结果非空则执行）
- `#`：将当前结果字符串复制一份追加到末尾（翻倍）
- `%`：将当前结果字符串原地反转

返回处理后的最终字符串中第 k 个字符（0-indexed）。若 k >= 最终长度，返回 '.'。

### 示例

**示例 1：**
```
输入: s = "a#b%*", k = 1
输出: "a"
解释:
  a → "a"
  # → "aa"
  b → "aab"
  % → "baa"
  * → "ba"
  ret[1] = 'a'
```

**示例 2：**
```
输入: s = "cd%#*#", k = 3
输出: "d"
解释:
  c → "c"
  d → "cd"
  % → "dc"
  # → "dcdc"
  * → "dcd"
  # → "dcddcd"
  ret[3] = 'd'
```

**示例 3：**
```
输入: s = "z*#", k = 0
输出: "."
解释:
  z → "z"
  * → ""
  # → ""
  长度为 0，k = 0 越界，返回 '.'
```

## 解题思路

本题与 3612 题操作规则相同，但关键区别在于：3612 只需返回完整字符串，而 3614 只需返回第 k 个字符，且 k 的范围可达 10^15。

**核心难点**：`#` 操作 `ret += ret` 会使字符串指数级增长。例如 60 个 `#` 操作会使长度达到 2^60，直接模拟必然导致 MLE。

**解决方案：逆向回溯算法**

既然只需要第 k 个字符，就不必构建完整字符串。核心思路是从最终状态逆向回溯，将"第 k 个字符在最终字符串中的位置"逐步映射回原始输入中的某个字符。

**算法步骤：**

1. **正向扫描**：只记录最终字符串长度 `len`（用 `long long`），不存储字符串内容
   - 小写字母：`len++`
   - `*`：`len = max(0, len - 1)`
   - `#`：`len *= 2`
   - `%`：`len` 不变

2. **边界检查**：若 `k >= len`，返回 `'.'`

3. **逆向回溯**：从 s 末尾向前遍历，维护 `curK` 和 `len`：
   - **小写字母 c**：它是最后一步追加的字符，位于 `len - 1` 位置。若 `curK == len - 1`，则答案就是 c；否则 `len--`
   - **`*`**：删除了末尾字符，回退时 `len++`，`curK` 不受影响
   - **`#`**：翻倍操作，前半部分和后半部分完全相同。`len /= 2`；若 `curK >= len`，说明在后半部分，映射到 `curK -= len`
   - **`%`**：反转操作，位置 `curK` 映射为 `len - 1 - curK`

## 代码实现

{% raw %}
```cpp
class Solution {
public:
    char processStr(string s, long long k) {
        long long len = 0;
        for (char c : s) {
            if (c >= 'a' && c <= 'z') {
                len++;
            } else if (c == '*' && len > 0) {
                len--;
            } else if (c == '#') {
                len *= 2;
            }
        }
        if (k >= len) {
            return '.';
        }

        long long curK = k;
        for (int i = (int)s.size() - 1; i >= 0; --i) {
            char c = s[i];
            if (c >= 'a' && c <= 'z') {
                if (curK == len - 1) {
                    return c;
                }
                len--;
            } else if (c == '*') {
                len++;
            } else if (c == '#') {
                len /= 2;
                if (curK >= len) {
                    curK -= len;
                }
            } else if (c == '%') {
                curK = len - 1 - curK;
            }
        }
        return '.';
    }
};
```
{% endraw %}

## 复杂度分析

- **时间复杂度**：O(n)，正向扫描一次 + 逆向回溯一次，各遍历字符串一次
- **空间复杂度**：O(1)，仅使用 `len` 和 `curK` 两个变量，无需存储字符串

## 总结

本题的核心在于从"构建完整字符串"的正向思维转向"追踪目标位置来源"的逆向思维：

1. `#` 操作的翻倍使字符串指数增长，正向模拟不可行
2. 逆向回溯时，每种操作都有明确的位置映射规则
3. 只追踪一个位置 `curK`，将 O(2^n) 的空间降为 O(1)

这种"只查询特定位置而字符串指数增长"的问题，逆向回溯是标准解法。
