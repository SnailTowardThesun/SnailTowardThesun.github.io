> 带额外约束的最短路有个通用套路——分层图：把约束维度并入状态一起跑 Dijkstra。飞行经停限制、免费换乘次数、以及本题的尾部连续段长，都是「扩状态换正确性」的同一招。

## 题目

LeetCode 3970. Shortest Path With At Most K Consecutive Identical Characters（最多 K 个连续相同字符的最短路径）

Difficulty: **Medium**

给定一个含 `n` 个节点的**有向加权**图（节点编号 `0` 到 `n-1`），`edges[i] = [ui, vi, wi]` 表示一条从 `ui` 指向 `vi`、权值为 `wi` 的有向边。另给定长度为 `n` 的字符串 `labels`（`labels[i]` 为节点 `i` 的字符标签）和整数 `k`。

从节点 `0` 走到节点 `n-1`，要求路径上所有节点的标签按顺序拼接后，**任意连续相同字符的个数都不超过 `k`**。返回满足约束的路径的最小总边权；不存在合法路径返回 `-1`。

约束：

- `1 <= n == labels.length <= 5 * 10^4`
- `0 <= edges.length <= 5 * 10^4`
- `0 <= ui, vi <= n-1` 且 `ui != vi`
- `1 <= wi <= 10^4`
- `labels` 由小写英文字母组成
- `1 <= k <= 50`

### 示例

```text
输入：n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], labels = "aab", k = 1
输出：3
解释：0→1→2 总权只有 2，但标签拼成 "aab" 出现 2 个连续 'a'，超过 k=1；
     只能直走 0→2（权 3），标签 "ab" 只有 1 个连续字符，合法。
```

```text
输入：n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], labels = "aab", k = 2
输出：2
解释：0→1→2 标签 "aab" 连续 'a' 恰为 2 个，不超过 k=2，总权 1+1=2。
```

```text
输入：n = 3, edges = [[0,1,1],[1,2,1]], labels = "aaa", k = 2
输出：-1
解释：唯一路径 0→1→2 的标签为 "aaa"，连续 'a' 有 3 个，无合法路径。
```

## 解题思路

### 第一步：认清为什么普通 Dijkstra 是错的

如果只以节点为状态跑 Dijkstra，到达同一节点时只保留最短的一条——但本题里**到达同一节点的不同路径，尾巴上的连续段长不同，后续哪些边还能走也随之不同**。「便宜但段长已满」的到达方式可能寸步难行，「贵但段长归 1」的反而走得通。

构造一个具体例子（labels = `"aaba"`，k = 2）：

```text
0 --1--> 1 --1--> 3        0 号 'a'，1 号 'a'，2 号 'b'，3 号 'a'
|         ^
5         1
+--2------+
```

- 直走 `0→1`（权 1）：标签 `"aa"`，尾段长 2 已满；再接 `1→3` 就是 3 个连续 'a'，违规；
- 绕行 `0→2→1`（权 5+1=6）：到 1 时标签 `"ab"`，尾段长 1，接 `1→3` 后是 `"aba"` + 'a' → 尾段 2，合法，总权 7。

只记节点的解法会把 `0→1` 的权 1 当作到 1 的最优，然后发现 `1→3` 走不了，把本可走通的整体方案判死。**结论：尾部连续段长必须进状态。**

### 第二步：分层图——把约束并进状态

状态定义为 `(节点 v, r)`，`r` = 到达 `v` 时以 `labels[v]` 结尾的连续段长度，取值 `1..k`。相当于把原图复制成 `k` 层，第 `r` 层的 `v` 表示「尾段长为 r 地站在 v」。

转移沿边 `u→v`（权 `w`）从状态 `(u, r)` 出发：

- `labels[v] == labels[u]`：段被接长，新段长 `r + 1`；若 `r + 1 > k`，这条边在当前状态走不得；
- `labels[v] != labels[u]`：字符切换把段打断，新段长归 `1`。

起点状态 `(0, 1)` 代价 0（`n == 1` 时起点即终点，答案 0）。边权 `wi >= 1` 全为正，Dijkstra 的贪心成立：**终点 `n-1` 的任意状态第一次出堆的代价就是答案**；堆耗尽仍没到终点则返回 `-1`。

### 第三步：一个容易被忽略的性质——路径可以不是简单路径

分层图里的走法**允许重复经过节点**。这不是宽松，而是必要：有时借一个环里的异字符打断连续段，是唯一的合法走法。

```text
labels = "aaba", k = 2
0 --1--> 1 --1--> 3
          ^     |
          |     |（1→3 权 1）
          1     |
          2 <---+  ... 实际边：0→1(1), 1→2(1), 2→1(1), 1→3(1)
```

所有**简单**路径只有 `0→1→3`，标签 `"aaa"` 连续段 3 超限——只枚举简单路径会答 `-1`。但走法 `0→1→2→1→3` 重复经过节点 1，标签 `"aabaa"` 最长连续段 2，合法，总权 4 才是正确答案。状态 Dijkstra 在分层图上天然支持重访，无需任何特判。

### 手算示例：走一遍官方示例 1

`edges = [[0,1,1],[1,2,1],[0,2,3]]`，`labels = "aab"`，`k = 1`：

1. 起点 `(0, 1)` 代价 0（标签 "a"，段长 1）；
2. 松弛 `0→1`（`labels[1]==labels[0]=='a'`）：新段长 2 > k=1，**该边被禁止**；松弛 `0→2`（'b' 切换）：新段长 1，代价 3，状态 `(2, 1)` 入堆；
3. 堆中仅 `(2,1)@3`，出堆时 `2 == n-1`，返回 3。

若 `k = 2`：第 2 步里 `0→1` 变为合法，状态 `(1, 2)@1` 入堆；随后松弛 `1→2`（'b' 切换）得 `(2, 1)@2`，先于 `(2,1)@3` 出堆，返回 2——正是示例 2。

### 复杂度分析

- 时间复杂度：`O(E·k·log(n·k))`——状态共 `n·k` 个（`5e4 × 50 = 2.5e6`），每条边在每个尾段长下至多松弛一次；
- 空间复杂度：`O(n·k + E)`。

## 代码实现

```python
import heapq
from math import inf


class Solution:
    def shortestPath(self, n: int, edges: list[list[int]], labels: str, k: int) -> int:
        graph = [[] for _ in range(n)]
        for x, y, w in edges:
            graph[x].append((y, w))

        dis = [[inf] * (k + 1) for _ in range(n)]
        dis[0][1] = 0  # 起点状态入堆前先落表，绕环回到起点的走法不会重复松弛
        h = [(0, 0, 1)]
        while h:
            d, x, cnt = heapq.heappop(h)
            if x == n - 1:
                return d
            if d > dis[x][cnt]:
                continue
            for y, w in graph[x]:
                new_cnt = 1 if labels[y] != labels[x] else cnt + 1
                new_dis = d + w
                if new_cnt <= k and new_dis < dis[y][new_cnt]:
                    dis[y][new_cnt] = new_dis
                    heapq.heappush(h, (new_dis, y, new_cnt))

        return -1
```

### 代码解析

- `dis[v]` 是长度 `k+1` 的一维数组（下标 0 弃用），`dis[v][r]` = 「尾段长 r 地到达 v」的最小代价——一个节点 k 个平行状态互不覆盖；
- `if x == n - 1: return d` 放在过期检查**之前**是安全的：堆按代价有序，某状态的最新条目必先于过期条目出堆，轮到过期条目时早已返回；
- `new_cnt = 1 if labels[y] != labels[x] else cnt + 1` 一行完成「同字符接长、异字符重开」两种转移，再由 `new_cnt <= k` 把违规转移拦在入堆之前；
- `dis[0][1] = 0` 先落表再入堆：绕环回到起点的走法因代价必大于 0 而不会重复松弛起点，也省去对起点的特殊判断；
- 惰性删除（`d > dis[x][cnt]` 跳过）让堆里可以残留过期条目，避免堆删除操作。

## 测试用例

覆盖官方示例、单节点图、不可达与反向边、重边取优、权值上界、k 翻转选路、非简单路径（绕环）等易错点；随机小图的期望值经独立参考实现 + 全走法有界枚举双重验证：

```python
def test_solution() -> None:
    solution = Solution()
    # 官方示例
    assert solution.shortestPath(3, [[0, 1, 1], [1, 2, 1], [0, 2, 3]], "aab", 1) == 3  # 便宜路径被约束封死
    assert solution.shortestPath(3, [[0, 1, 1], [1, 2, 1], [0, 2, 3]], "aab", 2) == 2  # k 放宽后便宜路径恢复合法
    assert solution.shortestPath(3, [[0, 1, 1], [1, 2, 1]], "aaa", 2) == -1  # 唯一路径 "aaa" 连续段 3 > 2
    # 边界：起点即终点 / 完全不可达
    assert solution.shortestPath(1, [], "a", 1) == 0
    assert solution.shortestPath(2, [], "ab", 5) == -1
    # 核心：为什么状态必须带段长——同一节点便宜的到达方式段长已满，贵的反而走得通
    # 0→1 便宜（代价 1）但 "aa" 段长 2，再接 1→3 就是 3 个 'a'；绕 0→2→1 段长归 1，才能接最后的 'a'
    assert solution.shortestPath(4, [[0, 1, 1], [0, 2, 5], [2, 1, 1], [1, 3, 1]], "aaba", 2) == 7
    assert solution.shortestPath(4, [[0, 1, 1], [0, 2, 5], [2, 1, 1], [1, 3, 1]], "aaba", 3) == 2  # "aaa" 放行
    # 换字符重开段：段满时绕一个异字符节点把段打断
    assert solution.shortestPath(4, [[0, 1, 1], [1, 2, 1], [0, 2, 3], [2, 3, 1]], "aaab", 2) == 4  # "aa" 段满，绕 b
    assert solution.shortestPath(4, [[0, 1, 1], [1, 2, 1], [0, 2, 3], [2, 3, 1]], "aaab", 3) == 3  # 直行 0→1→2→3
    # 重复边取较优者（题目不禁止重边，Dijkstra 天然正确）
    assert solution.shortestPath(2, [[0, 1, 7], [0, 1, 3]], "ab", 1) == 3
    # 权值上界也不影响正确性
    assert solution.shortestPath(3, [[0, 1, 10000], [1, 2, 10000]], "abc", 50) == 20000
    # 有向边方向陷阱：只有 1→0 的边，0 走不到 1（邻接表按 u→v 建，反向无法通行）
    assert solution.shortestPath(2, [[1, 0, 1]], "ab", 5) == -1
    # 非简单路径：最优解 0→1→2→1→3（权 4）会重复经过节点 1，借环里的 'b' 打断 a,a,a；
    # 只枚举简单路径的解法会误判 -1——分层 Dijkstra 允许重访节点，天然正确
    assert solution.shortestPath(4, [[0, 1, 1], [1, 2, 1], [2, 1, 1], [1, 3, 1]], "aaba", 2) == 4
    # 随机小图（期望值经独立参考实现 + 全走法有界枚举双重验证）
    assert (
        solution.shortestPath(
            6, [[1, 0, 2], [1, 5, 9], [3, 4, 9], [0, 5, 4], [5, 2, 2], [0, 4, 8], [0, 4, 2]], "bbccab", 3
        )
        == 4
    )
    assert (
        solution.shortestPath(
            4, [[1, 3, 7], [1, 3, 1], [0, 3, 1], [2, 3, 2], [2, 3, 1], [3, 0, 3], [2, 0, 1]], "bbbc", 1
        )
        == 1
    )
    assert (
        solution.shortestPath(
            4, [[1, 0, 1], [1, 0, 8], [0, 3, 8], [0, 1, 4], [2, 1, 2], [1, 0, 1], [1, 3, 7]], "bcbc", 1
        )
        == 8
    )
```

## 总结

- 只以节点为状态的最短路在「随身约束」下是错的：到达同一节点的不同尾段长对应不同的后续可行域，约束维度必须并入状态——`(节点, 尾段长)` 的分层图是标准解法；
- 终点首次出堆即可返回：正权图上堆序保证它就是最小值，且早退放在过期检查之前也安全，因为过期条目必后于其新鲜条目出堆；
- 别默认路径是简单路径：借环里的异字符打断连续段可能是唯一合法走法（本文 `aaba` 绕环例），状态 Dijkstra 天然支持重访，而简单路径枚举会漏解。
