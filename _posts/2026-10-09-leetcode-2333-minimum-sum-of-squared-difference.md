> 「最小化平方误差」是统计学里最小二乘法的核心，机器学习中的 MSE 损失就是它。本题只能逐步微调数值，于是「把总预算花在最大的差值上」的贪心削峰就成了最优策略。

## 题目

LeetCode 2333. Minimum Sum of Squared Difference（最小平方差之和）

Difficulty: **Medium**

给定两个长度为 `n` 的正整数数组 `nums1` 和 `nums2`（下标从 0 开始）。

可以对 `nums1` 执行两类操作任意次（可以为 0 次）：

- **类型 1**：任选下标 `i`，令 `nums1[i]` 加 1，最多共执行 `k1` 次；
- **类型 2**：任选下标 `i`，令 `nums1[i]` 减 1，最多共执行 `k2` 次。

返回执行操作后所有下标的平方差之和的最小值，即 `Σ(nums1[i] - nums2[i])^2` 的最小值。

数据范围：`1 <= n <= 10^5`，`1 <= nums1[i], nums2[i] <= 10^5`，`0 <= k1, k2 <= 10^9`。

### 示例

```
示例 1：
输入：nums1 = [1,2,3,4], nums2 = [2,10,20,19], k1 = 0, k2 = 0
输出：579
解释：无法执行操作，|1-2|² + |2-10|² + |3-20|² + |4-19|² = 1 + 64 + 289 + 225 = 579。

示例 2：
输入：nums1 = [1,4,10,12], nums2 = [5,8,6,9], k1 = 1, k2 = 1
输出：43
解释：差值绝对值为 [4,4,4,3]，用 2 次操作把两个 4 各降为 3，
      得 [3,3,4,3]，平方和 = 9 + 9 + 16 + 9 = 43。
```

## 解题思路

### 核心：桶计数 + 贪心削峰

关键观察有两点：

1. **每个位置互相独立**：对某个 `i` 的操作不影响其他位置的差值，且加 1 还是减 1 只看方向，所以总预算 `step = k1 + k2` 可以统一调度，每花 1 步就让某个 `|nums1[i] - nums2[i]|` 减 1（减到 0 为止）。
2. **边际收益递减**：把差值 `d` 降 1 可使平方和减少 `d^2 - (d-1)^2 = 2d - 1`，`d` 越大收益越高。因此每一步都应削当前最大的差值——即「削峰」。

如果用堆模拟需要 O(n log n)，但差值上界 `M = 10^5`，用**桶数组** `arr[d]` 统计差值为 `d` 的位置数，从大到小遍历，把高桶的计数整批搬到低一档，均摊后只要 O(n + M)。

### 手算示例

以测试用例为例：`nums1 = [7,11,4,19,11,5,6,1,8]`，`nums2 = [4,7,6,16,12,9,10,2,10]`，`k1 = 3`，`k2 = 6`。

差值绝对值为 `[3,4,2,3,1,4,4,1,2]`，桶计数为 `1:2, 2:2, 3:2, 4:3`，总预算 `step = 9`：

1. `d = 4` 桶有 3 个，全部搬到 `d = 3`，消耗 3 步（剩 6）→ `3:5, 2:2, 1:2`；
2. `d = 3` 桶有 5 个，全部搬到 `d = 2`，消耗 5 步（剩 1）→ `2:7, 1:2`；
3. `d = 2` 桶搬 1 个到 `d = 1`，消耗 1 步（剩 0）→ `2:6, 1:3`。

最终答案 `6 × 2² + 3 × 1² = 24 + 3 = 27`。

### 复杂度分析

- **时间复杂度**：O(n + M)，其中 `M = 10^5` 为差值上界，统计桶 O(n)，遍历搬运 O(M)。
- **空间复杂度**：O(M)，桶数组开销。

## 代码实现

{% raw %}
```cpp
class Solution {
public:
    long long minSumSquareDiff(vector<int> &nums1, vector<int> &nums2, int k1, int k2) {
        int n = nums1.size();
        long long ret = 0;
        vector<long long> arr(1e5 + 1, 0);

        // 桶计数：arr[d] = 差值绝对值为 d 的位置数
        for (auto i = 0; i < n; i++) {
            arr[abs(nums1[i] - nums2[i])]++;
        }

        // 贪心削峰：从最大的差值开始，整批搬到低一档，直到预算用尽
        int step = k1 + k2;
        for (int i = arr.size() - 1; i > 0 && step > 0; i--) {
            int change = step < arr[i] ? step : arr[i];
            step -= change;
            arr[i-1] += change;
            arr[i] -= change;
        }

        // 汇总平方和
        for (auto i = 0; i < arr.size(); i++) {
            ret += i * i * arr[i];
        }

        return ret;
    }
};
```
{% endraw %}

### 代码解析

- `arr` 下标即差值大小，值为该差值的个数，一次遍历完成统计。
- 搬运循环中 `change = min(step, arr[i])`：要么把当前桶清空，要么把剩余预算全部用完，整批移动避免了逐个模拟。
- `i > 0` 的边界保证差值最小只能降到 0，不会出现负差值（`arr[0]` 是合法落点）。
- 答案用 `long long`：`n` 个 `1e5` 的平方求和可达 `10^15` 量级，`int` 必然溢出。

## 测试用例

```cpp
TEST(Daily, 2333) {
    Solution s;

    // 预算用不完也会被差值 0 挡住
    vector<int> nums1{7,11,4,19,11,5,6,1,8};
    vector<int> nums2{4,7,6,16,12,9,10,2,10};
    auto k1 = 3, k2 = 6;
    EXPECT_EQ(s.minSumSquareDiff(nums1, nums2, k1, k2), 27);

    // 示例 1：零预算
    vector<int> a1{1,2,3,4}, b1{2,10,20,19};
    EXPECT_EQ(s.minSumSquareDiff(a1, b1, 0, 0), 579);

    // 示例 2：两步削峰
    vector<int> a2{1,4,10,12}, b2{5,8,6,9};
    EXPECT_EQ(s.minSumSquareDiff(a2, b2, 1, 1), 43);
}
```

## 总结

- 每步收益 `2d-1` 随 `d` 递增，最优策略永远是削当前最大的差值，贪心可证。
- 差值上界不大时，桶计数把堆的 O(n log n) 降到 O(n + M)，是「值域小」场景的通用优化。
- `k1 + k2` 与平方和都可能超出 `int`，返回值用 `long long` 是本题最容易翻车的细节。
