> 滑动窗口找不重复子串：右指针扩张收集新字符，撞上重复时左指针收缩吐出旧字符——双指针各走一趟，每个字符只进出窗口一次。

## 题目

LeetCode 3. Longest Substring Without Repeating Characters（无重复字符的最长子串）

Difficulty: **Medium**

给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。

约束：

- `0 <= s.length <= 5 * 10^4`
- `s` 由英文字母、数字、符号和空格组成

### 示例

```text
示例 1：
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，长度为 3。

示例 2：
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，长度为 1。

示例 3：
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，长度为 3。
注意答案必须是子串的长度，"pwke" 是子序列而不是子串。
```

## 解题思路

### 滑动窗口：右扩收新、撞重收缩

1. 维护窗口 `[left, right]` 与窗口内字符集合；
2. `right` 逐位右扩：新字符不在集合中，入集合并刷新最长；
3. 撞上重复字符时收缩 `left`：沿途字符逐个移出集合，直到把与 `s[right]` 相同的**旧字符**移过——集合中保留该字符的值（`right` 处的新出现接管它）；
4. 不变量：窗口内无重复，答案取窗口长度的最大值。

两个经典陷阱用例：

- `"abba"`：收缩过程把 `a` 移出了集合，末尾再遇到 `a` 不算重复（答案 2）；
- `"tmmzuxt"`：开头的 `t` 早在收缩时移出，末尾的 `t` 能重新入窗（答案 5，子串 `"mzuxt"`）。

### 另一种写法：记录每个字符的最后位置

用数组 `locs[256]` 记每个字符最后出现的下标。遍历时若 `locs[s[i]]` 落在当前窗口内（`> idx`），把左边界直接**跳**到该位置（无需逐步收缩），否则窗口继续右扩。两种写法都是 O(n)，跳位置版省去收缩循环、常数更小。

### 复杂度分析

- 时间复杂度：`O(n)`——`left`、`right` 各单调走一趟（跳位置版单趟循环）；
- 辅助空间复杂度：Python 集合为 `O(min(n, |Σ|))`；C++ 固定 256 项位置数组为 `O(1)`，字符串按常量引用传入，避免复制输入。

class Solution {
   public:
    int lengthOfLongestSubstring(const string& s) {
        int result = 0;
        array<int, 256> locs;
        locs.fill(-1);
        int idx = -1;
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            auto ch = static_cast<unsigned char>(s[i]);
            idx = max(idx, locs[ch]);
            result = max(result, i - idx);
            locs[ch] = i;
        }
        return result;
    }
};

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        n = len(s)
        if n == 0:
            return 0

        ret = 1  # 单字符自成合法窗口
        tmp = 1  # 当前窗口长度，恒等于 right - left + 1
        left, right = 0, 1
        container = {s[0]}  # 窗口内字符集合
        while right < n:
            if s[right] not in container:
                tmp += 1
                ret = max(ret, tmp)
                container.add(s[right])
            else:
                # 收缩到「与 s[right] 相同的旧字符」被移过为止：
                # 沿途字符移出集合；命中的那个字符不移出——right 处的新出现接管它
                while left <= right:
                    if s[left] == s[right]:
                        left += 1
                        tmp = right - left + 1
                        break
                    container.remove(s[left])
                    left += 1
                    tmp -= 1

            right += 1

        return ret

### 代码解析

- **C++ 版（跳位置）**：`idx` 是当前窗口左边界的前一格；`idx = max(idx, locs[ch])` 保证左边界只向右移动，`i - idx` 恰为当前窗口长度；`ch` 转为无符号字节后作下标，避免负下标越界；
- **Python 版（set 收缩）**：命中重复时内层 while 逐个吐出字符，注意**与 `s[right]` 相同的旧字符不移出集合**——`right` 处的新出现让它继续留在窗口里；
- `tmp` 恒等于 `right - left + 1`，收缩分支里直接按此式重置，避免逐项加减出错。

## 测试用例

```python
def test_solution() -> None:
    solution = Solution()

    # ---- 官方示例 ----
    assert solution.lengthOfLongestSubstring("abcabcbb") == 3
    assert solution.lengthOfLongestSubstring("bbbbb") == 1
    assert solution.lengthOfLongestSubstring("pwwkew") == 3

    # ---- 陷阱：收缩中旧字符已被移出，末尾同字符不算重复 ----
    assert solution.lengthOfLongestSubstring("abba") == 2
    assert solution.lengthOfLongestSubstring("tmmzuxt") == 5

    # ---- 边界：空串 / 单字符 / 空格 ----
    assert solution.lengthOfLongestSubstring("") == 0
    assert solution.lengthOfLongestSubstring("a") == 1
    assert solution.lengthOfLongestSubstring(" ") == 1

    # ---- 全不重复 ----
    assert solution.lengthOfLongestSubstring("abcdef") == 6
```

提交前用「枚举起点、向右扫描至首次重复」的 O(n²) 朴素版随机对照 2000 组，与滑动窗口版结果全部一致。

## 总结

- 滑动窗口的本质：窗口内维护「合法」状态，右扩收集、撞重收缩，双指针各走一趟 O(n)；
- 收缩的边界细节是本题考点：旧重复字符的去留（`abba`/`tmmzuxt` 两类陷阱）；
- set 收缩与最后位置跳转是同一思想的两种实现，后者常数更小，前者更直观。
