> 子序列计数在基因序列比对、文本指纹去重等场景中很常见。DNA 由 ATCG 四种字符组成，统计不同子序列数量正是生物信息学中的基础问题。

## 题目

LeetCode 940. Distinct Subsequences II（不同的子序列 II）

Difficulty: **Hard**

给定一个字符串 `s`，计算 `s` 的 **不同非空子序列** 的个数。因为答案可能很大，返回对 `10^9 + 7` 取余的结果。

**子序列**：通过原字符串删除一些（也可以不删）字符且不改变剩余字符相对顺序生成的新字符串。两个子序列不同当且仅当它们在某个位置上的字符不同。

### 示例

```
示例 1：
输入：s = "abc"
输出：7
解释：7 个不同的子序列分别是 "a", "b", "c", "ab", "ac", "bc", "abc"。

示例 2：
输入：s = "aba"
输出：6
解释：6 个不同的子序列分别是 "a", "b", "ab", "ba", "aa", "aba"。

示例 3：
输入：s = "aaa"
输出：3
解释：3 个不同的子序列分别是 "a", "aa", "aaa"。
```

## 解题思路

### 核心思路：按「结尾字符」分类的计数 DP

统计不同子序列的最大难点在于**去重**：同一子序列可能由多种删除方式得到（如 `"aba"` 中的 `"a"` 有两种来源）。直接枚举 2^n 个子序列再放进集合去重，时间与空间都会爆炸。

巧妙的做法是给子序列按**结尾字符**分桶。设：

```
dp[i][c] = 只考虑 s 的前 i 个字符时，以字符 c（'a'~'z'）结尾的不同子序列个数
```

这样「不同」就有了精确刻画：两个子序列不同 ⇔ 结尾字符不同，或结尾字符相同但同属一个桶内的不同计数。只要每个桶内不重复，总数就是 26 个桶之和。

### 状态转移

处理第 `i` 个字符 `ch = s[i-1]` 时：

1. **其余桶不受影响**：以其他字符结尾的子序列不会因多看一个字符而新增，故 `dp[i]` 先整体拷贝 `dp[i-1]`。
2. **以 `ch` 结尾的桶直接覆盖旧值**：

```
dp[i][ch] = sum(dp[i-1]) + 1
```

   把前一状态的每个不同子序列（含空串）末尾追加一个 `ch`，就得到全部以 `ch` 结尾的不同子序列；`+1` 对应「空串 + ch」，即子序列 `"ch"` 本身。

### 为什么覆盖式赋值能去重？

这是本题最关键的一点。直觉上「覆盖会丢失旧数据」，但这里恰恰相反：

旧集合中每个以 `ch` 结尾的子序列，去掉末尾 `ch` 后仍是前 `i-1` 个字符的某个子序列（可能是空串），它在第 2 步中会被重新追加 `ch` 扩展出来。因此**新的以 `ch` 结尾集合恰好完整覆盖旧集合**，且每个成员只由唯一来源生成，天然不含重复。

以 `s = "aba"` 为例：

```
i=1 (a): dp[1][a] = 0 + 1 = 1                     → {"a"}
i=2 (b): dp[2][b] = sum(dp[1]) + 1 = 1 + 1 = 2    → {"b", "ab"}
         dp[2][a] = 1（保持）
i=3 (a): dp[3][a] = sum(dp[2]) + 1 = 3 + 1 = 4    → {"a", "aa", "ba", "aba"}
         dp[3][b] = 2（保持）
答案 = 4 + 2 = 6 ✓
```

注意 `i=3` 时旧桶 `[a]` 里的 `"a"` 被覆盖为 4 个，但新的 4 个成员 `{"a", "aa", "ba", "aba"}` 完整包含了旧的 `"a"`，没有任何丢失。

### 复杂度分析

- **时间复杂度**：O(n × 26)，每个位置做一次 O(26) 的求和。
- **空间复杂度**：O(n × 26)；若只保留上一行，可用滚动数组优化到 O(26)。

## 代码实现

{% raw %}
```cpp
class Solution {
   public:
    int distinctSubseqII(string s) {
        const int MOD = 1e9 + 7;
        // dp[i][c]: 前 i 个字符中，以字符 c 结尾的不同子序列个数（模 MOD）
        vector<vector<int>> dp(s.size() + 1, vector<int>(26, 0));
        for (int i = 1; i <= s.size(); ++i) {
            dp[i] = dp[i - 1];
            // 以 s[i-1] 结尾的子序列 = 上一状态全部子序列（含空串）各追加该字符
            dp[i][s[i - 1] - 'a'] =
                (accumulate(dp[i - 1].begin(), dp[i - 1].end(), 0LL) + 1) % MOD;
        }
        return accumulate(dp[s.size()].begin(), dp[s.size()].end(), 0LL) % MOD;
    }
};
```
{% endraw %}

### 代码解析

- 用二维数组 `dp[i][c]` 记录每个前缀、每个结尾字符的计数，转移时先拷贝上一行再覆盖当前字符对应的桶。
- 求和使用 `accumulate` 并以 `0LL` 为初值：26 个桶各不超过 `MOD`，总和约 `2.6×10^10`，用 `long long` 累加不会溢出。
- 最终答案即最后一行 26 个桶之和，再对 `MOD` 取余。

## 测试用例

{% raw %}
```cpp
TEST(Daily, 940) {
    Solution s;

    // 基本用例：无重复字符
    EXPECT_EQ(s.distinctSubseqII("abc"), 7);  // a, b, c, ab, ac, bc, abc

    // 边界用例：含重复字符（考察去重）
    EXPECT_EQ(s.distinctSubseqII("aba"), 6);  // a, b, ab, ba, aa, aba
    EXPECT_EQ(s.distinctSubseqII("aaa"), 3);  // a, aa, aaa

    // 边界用例：单字符
    EXPECT_EQ(s.distinctSubseqII("a"), 1);
}
```
{% endraw %}

## 总结

这道 Hard 难度的题，难点不在转移方程本身，而在**去重的设计**。「按结尾字符分桶 + 覆盖式赋值」把看似复杂的重复问题化归为一行赋值语句：新字符能把上一状态的全体子序列（含空串）各扩展一份，且这份新集合恰好吞并旧桶、绝不重复。理解了「为什么覆盖不会丢信息」，这题就从 Hard 变成了 Medium 的手感。此外，`accumulate` 配 `0LL` 初值防止 26 个模数相加溢出，也是计数类 DP 的常见细节。
