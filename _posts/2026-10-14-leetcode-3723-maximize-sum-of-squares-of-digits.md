> 同样和为 10，9+1 的平方和是 82，5+5 只有 50——平方函数的凸性让"集中"永远胜过"平均"，这正是本题贪心策略的数学根源。

## 题目

LeetCode 3723. Maximize Sum of Squares of Digits（数位平方和的最大值）

Difficulty: **Medium**

给你两个**正整数** `num` 和 `sum`。如果一个正整数 `n` 满足以下两个条件，则称其为**好整数**：

1. `n` 的位数**恰好**为 `num`；
2. `n` 的各位数字之和**恰好**为 `sum`。

一个**好整数** `n` 的**分数**定义为 `n` 的各位数字的**平方和**。

返回一个字符串，表示能够获得**最大分数**的**好整数** `n`。若有多个可能的好整数，返回其中**最大**的；若不存在这样的好整数，返回空字符串 `""`。

### 示例

```
输入：num = 2, sum = 3
输出："30"
解释：好整数有 12、21、30，分数（各位平方和）分别为 5、5、9，
     30 的分数最大，返回 "30"。

输入：num = 2, sum = 17
输出："98"
解释：好整数有 89、98，分数均为 8*8 + 9*9 = 145，
     返回其中更大的 "98"。

输入：num = 1, sum = 10
输出：""
解释：不存在一位数使其数字之和为 10，返回空字符串。
```

## 解题思路

这是一道构造类贪心题，关键洞察是**平方函数是凸函数**：当 `a + b <= 9` 时，`a*a + b*b <= (a+b)*(a+b)`，即把两个数字合并成一个更大的数字，平方和不减反增。所以同样总和下，数字越"集中"，平方和越大。

1. **无解判断**：`num` 位数各位数字之和最大为 `9 * num`，若 `9 * num < sum`，则不存在好整数，返回空字符串；
2. **最大化分数**：由凸性，数字应尽可能集中为 9。最优数字组合为 `sum / 9` 个 9、一个余数位 `sum % 9`（若非 0）、其余位全为 0；
3. **同分数取最大数**：同一组数字降序排列即为最大的数——9 在最前、余数位次之、0 垫底。

以 `num = 2, sum = 17` 为例，手算如下：

```
sum / 9 = 1 → 先放一个 9
sum % 9 = 8 → 再放一个 8
位数补齐 → 已满 2 位，不再补 0
结果 = "98"
```

以 `num = 2, sum = 3` 为例：

```
sum / 9 = 0 → 没有 9
sum % 9 = 3 → 放一个 3
补 0 到 2 位 → "30"
```

### 复杂度分析

- **时间复杂度**：O(num)，构造长度为 num 的答案字符串。
- **空间复杂度**：O(num)，答案字符串本身。

## 代码实现

```cpp
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        string ret = "";
        if (9 * num < sum) {
            return ret;
        }

        // 由凸性数字尽量集中：先放 sum/9 个 9
        ret += string(sum / 9, '9');
        // 余数位（若非 0）紧跟其后
        if (sum % 9 != 0) {
            ret += '0' + sum % 9;
        }
        // 剩余位用 0 补齐到恰好 num 位
        ret += string(num - ret.size(), '0');

        return ret;
    }
};
```

### 代码解析

- **无解守卫**：`9 * num < sum` 提前返回空串，注意 `num` 最大 2*10^5，`9 * num` 不会溢出 `int`；
- **三段式构造**：`sum / 9` 个 9 + 余数位 + 前导补 0，顺序恰好就是降序排列，天然满足"同分数取最大数"的要求；
- **`ret.size()` 的妙用**：补 0 的数量直接用 `num - ret.size()` 计算，无需额外变量，也自动处理了余数为 0 或 9 恰好填满所有位的边界情况。

## 测试用例

```cpp
TEST(Daily, 3723) {
    Solution s;

    // 官方示例 1：好整数 12/21/30 中 30 的平方和最大
    EXPECT_EQ("30", s.maxSumOfSquares(2, 3));

    // 官方示例 2：89 与 98 平方和相同，返回更大的 98
    EXPECT_EQ("98", s.maxSumOfSquares(2, 17));

    // 官方示例 3：一位数的数字和无法达到 10，无解
    EXPECT_EQ("", s.maxSumOfSquares(1, 10));

    // 边界：sum = 9，无余数位，1 个 9 + 1 个 0
    EXPECT_EQ("90", s.maxSumOfSquares(2, 9));

    // 边界：sum 恰好填满所有位
    EXPECT_EQ("999", s.maxSumOfSquares(3, 27));

    // 边界：num 较大而 sum 很小，1 后补 0
    EXPECT_EQ("10000", s.maxSumOfSquares(5, 1));
}
```

## 总结

1. 平方函数的凸性是本题的核心：固定总和时，数字越集中平方和越大，贪心地把数字合并成 9；
2. 最优解固定为 `sum/9` 个 9 + 余数位 + 补 0，降序排列同时满足"同分数取最大数"；
3. 别忘了无解判断 `9 * num < sum`，以及 `sum` 恰为 9 的倍数时没有余数位的边界。
