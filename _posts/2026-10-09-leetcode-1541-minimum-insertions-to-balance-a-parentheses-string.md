> 括号平衡问题在编译器语法检查、代码编辑器高亮和 XML 校验中无处不在，贪心计数是处理它的利器。

## 题目

LeetCode 1541. Minimum Insertions to Balance a Parentheses String（平衡括号字符串的最少插入次数）

Difficulty: **Medium**

给你一个括号字符串 `s`，它只包含字符 `'('` 和 `')'`。一个平衡的括号字符串需满足：

- 每个左括号 `'('` 都必须对应**两个连续**的右括号 `"))"`；
- 左括号 `'('` 必须在对应的连续两个右括号 `"))"` 之前。

空字符串也视为平衡的。你可以在字符串的任意位置插入字符 `'('` 或 `')'`，返回使 `s` 平衡所需的最少插入次数。

### 示例

```
输入：s = "(()))"
输出：1
解释：在第二个 ')' 后插入一个 '(' 即可平衡。

输入：s = "()))"
输出：3

输入：s = "()()"
输出：0
```

## 解题思路

### 一次遍历 + 贪心计数

这道题的核心规则是：**每个 `'('` 需要两个连续的 `')'` 与之配对**。我们可以一次遍历，用贪心策略统计缺失的括号数量。

维护两个变量：

- `l`：当前未匹配的 `'('` 数量；
- `ret`：需要插入的字符总数。

逐个字符处理：

1. **`'('`**：未匹配数加一（`l++`）；
2. **`')'`**：先处理与左括号的配对——若 `l > 0` 则消耗一个 `'('`（`l--`），否则缺少 `'('`，需插入一个（`ret++`）；接着处理右括号的成对要求——检查下一个字符，若也是 `')'` 则成对消耗（跳过下一字符），否则这个 `')'` 缺少配对，需再插入一个 `')'`（`ret++`）。

遍历结束后，每个仍未匹配的 `'('` 还需要两个 `')'`，即 `ret += l * 2`。

以 `"()())))()"` 为例：第 4、5 位是 `))` 正常配对；第 6 位 `)` 后面是 `(`，缺一个 `')'`，`ret++`；末尾 `()` 正常；最终未匹配的 `'('` 数为 1，补 `ret += 2`，总计 3。

### 复杂度分析

- **时间复杂度**：O(n)，每个字符最多访问一次。
- **空间复杂度**：O(1)，只使用常数额外空间。

## 代码实现

```cpp
class Solution {
   public:
    int minInsertions(string s) {
        int ret = 0;
        int l = 0;

        for (auto i = 0; i < s.size(); ++i) {
            if (s.at(i) == '(') {
                l++;
                continue;
            }

            if (l > 0) {
                l--;
            } else {
                ret++;
            }

            if (i < s.size() - 1 && s.at(i + 1) == ')') {
                i++;
            } else {
                ret++;
            }
        }

        ret += l * 2;

        return ret;
    }
};
```

### 代码解析

- **贪心的正确性**：遇到 `')'` 时优先用已有的 `'('` 匹配，避免插入多余的 `'('`；右括号优先两两成对，避免插入多余的 `')'`，每一步的局部最优即全局最优。
- **跳过成对的 `))`**：当 `s[i] == ')'` 且 `s[i+1] == ')'` 时，直接 `i++` 跳过下一个字符，保证"连续两个右括号"的约束被正确处理。
- **尾部补偿**：遍历完成后剩下的每个 `'('` 都需要两个 `')'`，用 `ret += l * 2` 一次性补齐。

## 测试用例

```cpp
TEST(Daily, 1541) {
    Solution s;
    // 正常配对加一次插入
    EXPECT_EQ(s.minInsertions("()())))()"), 3);
    // 缺少左括号
    EXPECT_EQ(s.minInsertions("(()))"), 1);
    // 连续右括号
    EXPECT_EQ(s.minInsertions("()))"), 3);
    // 已经平衡
    EXPECT_EQ(s.minInsertions("()()"), 0);
}
```

## 总结

1. 每个左括号要配两个**连续**右括号，一次遍历用 `l` 跟踪可用左括号；
2. 右括号优先两两成对，落单就补插，`ret` 记录插入次数；
3. 尾部剩余左括号每个补两个右括号，O(n) 时间、O(1) 空间。
