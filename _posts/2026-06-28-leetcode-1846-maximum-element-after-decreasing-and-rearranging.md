> 数组的重排和调整操作在数据处理和优化问题中经常出现，这道题展示了如何在约束条件下最大化目标值。

## 题目

**题目名称**: 减小和重新排列数组后的最大元素  
**难度**: 中等  
**题目编号**: 1846

给你一个正整数数组 `arr`。请你对 `arr` 执行一些操作（也可以不进行任何操作），使得数组满足以下条件：

1. `arr` 中第一个元素必须为 1
2. 任意相邻两个元素的差的绝对值小于等于 1

你可以执行以下 2 种操作任意次：
- 减小 `arr` 中任意元素的值，使其变为一个更小的正整数
- 重新排列 `arr` 中的元素，你可以以任意顺序重新排列

请你返回执行以上操作后，在满足前文所述的条件下，`arr` 中可能的最大值。

### 示例

**示例 1**:
```
输入: arr = [2,2,1,2,1]
输出: 2
解释: 可以通过重新排列数组使其变为 [1,2,2,2,1]，满足条件且最大值为 2
```

**示例 2**:
```
输入: arr = [100,1,1000]
输出: 3
解释: 可以通过操作得到 [1,2,3]，满足条件且最大值为 3
```

**示例 3**:
```
输入: arr = [1,2,3,4,5]
输出: 5
解释: 数组已经满足条件，最大值为 5
```

## 解题思路

这道题的核心思想是**贪心算法**。我们需要在满足约束条件的前提下，尽可能让数组中的元素值最大化。

### 算法步骤

1. **排序策略**: 首先对数组进行升序排序，这样可以从小到大处理元素，便于后续的贪心调整。

2. **第一个元素处理**: 根据题目要求，第一个元素必须为 1。如果排序后的第一个元素不是 1，则将其强制设为 1。

3. **贪心调整**: 遍历数组，对于每个位置 `i`（从 1 开始），检查当前元素与前一个元素的差值：
   - 如果差值大于 1，则将当前元素调整为 `arr[i-1] + 1`
   - 这样可以保证相邻元素差值不超过 1，同时尽可能保持较大的值

4. **最终结果**: 数组最后一个元素即为可能的最大值。

### 为什么这样是正确的？

- 排序后，我们从小到大处理元素，确保每个位置的值都不会超过前面的值太多
- 通过贪心调整，我们让每个元素尽可能取到最大值（即前一个元素 + 1）
- 由于只能减小元素值，不能增加，所以这种方法能够得到最优解

### 复杂度分析

- **时间复杂度**: O(n log n)，主要是排序的时间复杂度
- **空间复杂度**: O(1)，只使用了常数级别的额外空间

## 代码实现

```cpp
class Solution {
public:
    int maximumElementAfterDecrementingAndRearranging(vector<int> &arr) {
        int n = arr.size();
        sort(arr.begin(), arr.end());
        if (arr[0] != 1) {
            arr[0] = 1;
        }

        for (int i = 1; i < n; i++) {
            if (abs(arr[i] - arr[i - 1]) > 1) {
                arr[i] = arr[i - 1] + 1;
            }
        }
        return arr[n - 1];
    }
};
```

### 代码说明

1. 使用 `sort` 对数组进行升序排序
2. 强制将第一个元素设为 1（如果还不是 1）
3. 遍历数组，对每个元素进行贪心调整
4. 返回数组最后一个元素作为结果

这道题展示了贪心算法在约束优化问题中的应用，通过合理的排序和调整策略，我们能够高效地找到最优解。
