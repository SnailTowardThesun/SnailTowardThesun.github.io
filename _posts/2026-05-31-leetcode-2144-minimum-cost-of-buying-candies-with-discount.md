> 糖果店促销策略在零售业中非常常见，理解这种"买二送一"优惠的计算方式有助于优化购物方案。

## 题目

LeetCode 2144. Minimum Cost of Buying Candies With Discount（购买糖果的最小成本）

Difficulty: **Easy**

给定一个整数数组 cost，其中 cost[i] 是第 i 个糖果的价格。

每买两个糖果，商店会赠送一个免费糖果，但免费糖果的价格必须不超过所购买的两个糖果中价格最低的那个。

请返回购买所有糖果的最小成本。

### 示例

```
示例 1：
输入：cost = [6,5,7,9,2,2]
输出：23
解释：
购买价格为 9 和 7 的糖果，免费获得价格为 6 的糖果；
购买价格为 5 和 2 的糖果，免费获得价格为 2 的糖果；
总花费为 9+7+5+2 = 23

示例 2：
输入：cost = [1,2,3]
输出：5
解释：
购买价格为 3 和 2 的糖果，免费获得价格为 1 的糖果，
总花费为 3+2 = 5

示例 3：
输入：cost = [1]
输出：1
```

## 解题思路

这道题的关键在于：如何最大化免费糖果的价值。

### 核心思路

1. **贪心策略**：为了最小化成本，我们希望免费获得的糖果价格尽可能高。

2. **排序后分组**：
   - 将糖果价格按升序排序
   - 从最贵的开始，每三个糖果为一组
   - 前两个（最贵的）需要付费购买
   - 第三个（最便宜的）免费获得

3. **数学表达**：
   - 排序后，假设糖果价格为 a1 ≤ a2 ≤ a3 ≤ ... ≤ an
   - 每三个一组：(a1, a2, a3), (a4, a5, a6), ...
   - 每组只需支付前两个的费用

### 算法详解

以示例 1 的 cost = [6,5,7,9,2,2] 为例：

```
步骤 1：排序
cost = [2, 2, 5, 6, 7, 9]

步骤 2：从后往前每隔三个取一个减去
从索引 n-3 = 3 开始：
  - ret = 2 + 2 + 5 + 6 + 7 + 9 = 31
  - i = 3: ret -= cost[3] = 31 - 6 = 25
  - i = 0: ret -= cost[0] = 25 - 2 = 23

最终结果：23
```

验证：从后往前每三个一组
- 索引 5,4,3 → 付 9+7，免费 6
- 索引 2,1,0 → 付 5+2，免费 2
- 总花费 = 9+7+5+2 = 23 ✓

## 代码实现

{% raw %}
```cpp
class Solution {
public:
    int minimumCost(vector<int>& cost) {
        int ret = 0;
        for (auto i : cost) {
            ret += i;
        }

        if (cost.size() <= 2) {
            return ret;
        }

        std::sort(cost.begin(), cost.end());
        for (int i = cost.size() - 3; i >= 0; i-=3) {
            ret -= cost[i];
        }

        return ret;
    }
};
```
{% endraw %}

### 代码解析

1. **求总和**：先将所有糖果价格相加
2. **边界处理**：如果糖果数量 ≤ 2，无法享受优惠，直接返回总和
3. **排序**：将糖果价格按升序排列
4. **减去免费糖果**：从后往前，每隔三个位置减去一个（免费糖果）

### 复杂度分析

- **时间复杂度**: O(n log n)，排序操作
- **空间复杂度**: O(1)，原地排序（如果不算 sort 额外的空间）

## 总结

这道题的关键是理解"买二送一"的促销规则：通过将糖果按价格升序排序，每三个一组，前两个付费购买，第三个免费获得。这样可以确保我们为较贵的糖果付费，而让较便宜的糖果免费。
