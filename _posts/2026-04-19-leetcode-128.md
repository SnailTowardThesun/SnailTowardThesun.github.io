> 最长连续序列用哈希集合实现O(n)，关键只在「序列起点」开始数：x-1 不在集合里，x 才是某段的开头。

## 题目

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请设计并实现时间复杂度为 `O(n)` 的算法解决此题。

约束：

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

### 示例

```text
示例 1：
输入：nums = [100, 4, 200, 1, 3, 2]
输出：4
解释：最长连续序列是 [1, 2, 3, 4]，长度为 4

示例 2：
输入：nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
输出：9

示例 3：
输入：nums = [0]
输出：1
```

## 解题思路

### 只从序列起点开始数

把所有数字放进哈希集合（去重），遍历集合中的每个数字 `x`：

1. 若 `x - 1` **不在**集合中，说明 `x` 是某段连续序列的起点——只有起点才需要向后数；
2. 从起点开始，`x+1`、`x+2` …… 逐个查集合直到断开，得到这段的长度；
3. 若 `x - 1` 在集合中，`x` 属于某段的中部，直接跳过——它会被自己那段的起点数到。

为什么是 O(n)：每个数字至多被访问两次（一次外层遍历、一次被某段起点向后数到），合计 O(n)。若不做起点判断，每个数字都向后数一遍会退化到 O(n²)。

### 复杂度分析

- 时间复杂度：`O(n)`，每个数字至多被访问两次；
- 空间复杂度：`O(n)`，哈希集合存储所有数字。

> 另一版实现（见仓库 hot100 目录）：去重排序后一次遍历做游程扫描，相邻差 1 则游程 +1，更直观但排序主导的复杂度是 O(n log n)，不满足题目进阶要求。

class Solution {
    public:
        int longestConsecutive(vector<int> &nums) {
            unordered_map<int, int> mp;  // 数字 -> 是否已访问（局部变量，可重复调用）
            for (int i = 0; i < nums.size(); i++)
                mp[nums[i]] = 1;

            int result = 0;
            for (int i = 0; i < nums.size(); i++) {
                int sum = 1;
                if (mp.count(nums[i]) && mp[nums[i]]) {
                    mp[nums[i]] = 0;
                    int left = nums[i] - 1;
                    while (mp.count(left) && mp[left]) {
                        mp[left--] = 0;
                        sum++;
                    }
                    int right = nums[i] + 1;
                    while (mp.count(right) && mp[right]) {
                        mp[right++] = 0;
                        sum++;
                    }
                }
                if (result < sum) result = sum;
            }
            return result;
        }
};

class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        num_set = set(nums)  # 去重 + O(1) 查询
        ret = 0
        for x in num_set:
            if x - 1 not in num_set:  # 只从序列起点开始数：x 前面没有相邻数
                run = 1
                while x + run in num_set:
                    run += 1
                ret = max(ret, run)
        return ret

### 代码解析

- **两个版本是同一思路的两种写法**：C++ 版用「访问标记 + 双向扩展」——遇到未访问的数字就向左右两边扩展并把路过的数字标记为已访问（这也是每个数字至多访问两次的保证）；Python 版用「起点判定 + 单向扩展」——`x - 1` 不在集合中才向后数，写法更短；
- C++ 的 `mp` 必须是**函数内局部变量**：若作成员变量，同一实例第二次调用会读到上一次残留的「已访问」标记，直接漏数（原文旧版踩过这个坑，已修正）；
- Python 遍历 `set` 而非原数组：重复元素天然只访问一次；
- 空数组时循环不执行，自然返回 0，无需特判。

## 总结

- 哈希集合去重后只从「序列起点」（`x-1` 不在集合）开始向后数，每个数字至多访问两次，O(n) 时间、O(n) 空间；
- 不判起点会让每个数字都向后扫一遍，退化 O(n²)——起点判定就是这道题的全部考点；
- 排序 + 游程扫描也能过，但 O(n log n) 不满足题目进阶要求，适合作为对照实现。
