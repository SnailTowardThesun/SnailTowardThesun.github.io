> 最长连续序列用哈希集合实现O(n)，关键只在「序列起点」开始数：x-1 不在集合里，x 才是某段的开头。

## 题目

LeetCode 128. Longest Consecutive Sequence（最长连续序列）

Difficulty: **Medium**

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请设计并实现时间复杂度为 `O(n)` 的算法解决此题。

约束：

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

### 示例

```text
示例 1：
输入：nums = [100, 4, 200, 1, 3, 2]
输出：4
解释：最长连续序列是 [1, 2, 3, 4]，长度为 4

示例 2：
输入：nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
输出：9

示例 3：
输入：nums = [1,0,1,2]
输出：3
```

## 解题思路

### 只从序列起点开始数

把所有数字放进哈希集合（去重），遍历集合中的每个数字 `x`：

1. 若 `x - 1` **不在**集合中，说明 `x` 是某段连续序列的起点——只有起点才需要向后数；
2. 从起点开始，`x+1`、`x+2` …… 逐个查集合直到断开，得到这段的长度；
3. 若 `x - 1` 在集合中，`x` 属于某段的中部，直接跳过——它会被自己那段的起点数到。

为什么是 O(n)：每个数字至多被访问两次（一次外层遍历、一次被某段起点向后数到），合计 O(n)。若不做起点判断，每个数字都向后数一遍会退化到 O(n²)。

### 复杂度分析

- 时间复杂度：平均 `O(n)`，每段连续序列只扩展一次，哈希查询平均 O(1)；
- 空间复杂度：`O(n)`，哈希集合存储所有数字。

> 题目明确要求 O(n)，并非可选进阶。仓库 Hot 100 版已与本文统一为哈希集合解法；排序扫描可作对照，但不满足该要求。

class Solution {
   public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> values(nums.begin(), nums.end());
        int result = 0;
        for (int x : values) {
            if (!values.contains(x - 1)) {
                int length = 1;
                while (values.contains(x + length)) ++length;
                result = max(result, length);
            }
        }
        return result;
    }
};

class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        num_set = set(nums)
        ret = 0
        for x in num_set:
            if x - 1 not in num_set:
                run = 1
                while x + run in num_set:
                    run += 1
                ret = max(ret, run)
        return ret

### 代码解析

- 两个版本都遍历去重后的集合，只在 `x - 1` 不存在时扩展，避免重复起点触发重复扫描；
- 集合在函数内部创建，每次调用独立，内存不会跨调用保留历史输入；
- 空数组时循环不执行，自然返回 0；复杂度依赖哈希查询平均 O(1)。

```python
def test_solution() -> None:
    solution = Solution()

    # ---- 官方示例 1：[1,2,3,4] ----
    assert solution.longestConsecutive([100, 4, 200, 1, 3, 2]) == 4

    # ---- 官方示例 2：[0..8] 全连续 ----
    assert solution.longestConsecutive([0, 3, 7, 2, 5, 8, 4, 6, 0, 1]) == 9

    # ---- 官方示例 3：重复值 ----
    assert solution.longestConsecutive([1, 0, 1, 2]) == 3

    # ---- 单元素 ----
    assert solution.longestConsecutive([0]) == 1

    # ---- 空数组 ----
    assert solution.longestConsecutive([]) == 0

    # ---- 重复元素不延长连续段 ----
    assert solution.longestConsecutive([1, 2, 0, 1]) == 3

    # ---- 无任何连续：各成一段 ----
    assert solution.longestConsecutive([10, 30, 20]) == 1

    # ---- 负数 ----
    assert solution.longestConsecutive([-2, -1, 1, 2, 3]) == 3

    # ---- 大量重复起点：必须遍历集合，避免重复扫描同一段 ----
    assert solution.longestConsecutive([0] * 5000 + list(range(5000))) == 5000
```

## 总结

- 哈希集合去重后只从「序列起点」（`x-1` 不在集合）开始向后数，每个数字至多访问两次，O(n) 时间、O(n) 空间；
- 不判起点会让每个数字都向后扫一遍，退化 O(n²)——起点判定就是这道题的全部考点；
- 排序 + 游程扫描也能过，但 O(n log n) 不满足题目要求，适合作为对照实现。
