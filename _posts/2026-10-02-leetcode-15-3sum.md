> 排序后固定一个数，把剩下的问题降维成两数之和——双指针 O(n²)，去重要在三个位置同时做。

## 题目

LeetCode 15. 3Sum（三数之和）

Difficulty: **Medium**

给你整数数组 nums，找出所有和为 0 且不重复的三元组。

### 示例

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]

输入：nums = [0,0,0]
输出：[[0,0,0]]
```

## 解题思路

### 排序 + 固定一位 + 双指针

1. 排序后，若 nums[k] > 0，后面的数都非负，三数之和不可能为 0，直接结束。
2. 固定 k，在 `[k+1, n-1]` 上用双指针找和为 `-nums[k]` 的两个数。
3. 和小于目标移动左指针，大于移动右指针。
4. **去重**：
   - 外层 k 与前一个数相同则跳过；
   - 找到解后，左右指针分别跳过相邻的重复值。

### 复杂度分析

- **时间复杂度**：O(n²)。
- **空间复杂度**：O(1)，不计输出与排序栈。

## 代码实现

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());

        for (int k = 0; k < nums.size(); ++k) {
            if (nums[k] > 0) break;
            if (k > 0 && nums[k] == nums[k - 1]) continue;

            int target = 0 - nums[k];
            int i = k + 1, j = nums.size() - 1;
            while (i < j) {
                if (nums[i] + nums[j] == target) {
                    res.push_back({nums[k], nums[i], nums[j]});
                    while (i < j && nums[i] == nums[i + 1]) ++i;
                    while (i < j && nums[j] == nums[j - 1]) --j;
                    ++i; --j;
                } else if (nums[i] + nums[j] < target) {
                    ++i;
                } else {
                    --j;
                }
            }
        }
        return res;
    }
};
```

### 代码解析

- 找到解后的两个 while 循环是去重关键，最后还要各移动一步离开当前值。

## 测试用例

```cpp
TEST(Daily, 15) {
    Solution s;
    vector<int> nums1 = {-1, 0, 1, 2, -1, -4};
    EXPECT_EQ(s.threeSum(nums1).size(), 2);
    vector<int> nums4 = {-2, 0, 0, 2, 2};
    EXPECT_EQ(s.threeSum(nums4).size(), 1);
}
```

## 总结

1. 排序把问题降维成双指针两数之和；
2. nums[k] > 0 提前剪枝；
3. 外层和找到解后都要跳过重复值。
