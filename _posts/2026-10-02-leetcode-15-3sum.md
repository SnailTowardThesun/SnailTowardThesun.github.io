> 排序后固定一个数，把剩下的问题降维成两数之和——双指针 O(n²)，去重要在三个位置同时做。

## 题目

LeetCode 15. 3Sum（三数之和）

Difficulty: **Medium**

给你整数数组 nums，找出所有和为 0 且不重复的三元组。

### 示例

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]

输入：nums = [0,0,0]
输出：[[0,0,0]]
```

## 解题思路

### 排序 + 固定一位 + 双指针

1. 排序后，若 nums[k] > 0，后面的数都非负，三数之和不可能为 0，直接结束。
2. 固定 k，在 `[k+1, n-1]` 上用双指针找和为 `-nums[k]` 的两个数。
3. 和小于目标移动左指针，大于移动右指针。
4. **去重**：
   - 外层 k 与前一个数相同则跳过；
   - 找到解后，左右指针分别跳过相邻的重复值。

### 复杂度分析

- **时间复杂度**：O(n²)。
- **辅助空间复杂度**：不计输出，双指针部分 O(1)；C++ `std::sort` 的常见实现使用 O(log n) 栈，Python `list.sort()` 最坏需要 O(n) 临时缓冲区。

### 反面教材：为什么「先生成重复再去重」会超时

直觉写法：对每个 i 用哈希 twoSum 扫出**所有**配对，`set` 去重后输出。复杂度同样是 O(n²)，但在全零数组 n=3000 上会生成约 **450 万**个重复候选（每个还要 `sorted + tuple + hash` 进 set），再叠加每轮 `nums[i+1:]` 的 O(n) 切片复制——判题机直接 TLE。教训：**去重要在生成侧做（跳过重复），而不是生成后兜底**。

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());

        for (int k = 0; k < nums.size(); ++k) {
            if (nums[k] > 0) break;
            if (k > 0 && nums[k] == nums[k - 1]) continue;

            int target = 0 - nums[k];
            int i = k + 1, j = nums.size() - 1;
            while (i < j) {
                if (nums[i] + nums[j] == target) {
                    res.push_back({nums[k], nums[i], nums[j]});
                    while (i < j && nums[i] == nums[i + 1]) ++i;
                    while (i < j && nums[j] == nums[j - 1]) --j;
                    ++i; --j;
                } else if (nums[i] + nums[j] < target) {
                    ++i;
                } else {
                    --j;
                }
            }
        }
        return res;
    }
};

{% highlight python %}
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()  # 排序是跳重与双指针的前提
        n = len(nums)
        ret: list[list[int]] = []

        for i in range(n - 2):
            if nums[i] > 0:  # 最小的数都 > 0，后面不可能凑出 0
                break
            if i > 0 and nums[i] == nums[i - 1]:  # 首元素跳重：同值的答案已找完
                continue

            left, right = i + 1, n - 1
            while left < right:
                s = nums[i] + nums[left] + nums[right]
                if s < 0:
                    left += 1
                elif s > 0:
                    right -= 1
                else:
                    ret.append([nums[i], nums[left], nums[right]])
                    left += 1
                    right -= 1
                    while left < right and nums[left] == nums[left - 1]:  # 第二个数跳重
                        left += 1
                    while left < right and nums[right] == nums[right + 1]:  # 第三个数跳重
                        right -= 1

        return ret

### 代码解析

- 找到解后必须离开当前配对并跳过重复值：C++ 先跳重再移动，Python 先移动再跳重。
- 两个版本的跳重写法方向相反但等价：C++ 先「跳到同值段末尾」再 `++i; --j`，Python 是「先各走一步」再跳过与**前一个**（已走过的）相同的值——都保证同一组答案只生成一次。
- Python 版先 `left += 1; right -= 1` 再比较 `nums[left] == nums[left - 1]`：`left - 1` 恰是刚记录过的位置，比较的是「新值是否与刚用过的值相同」。

```python
def test_solution() -> None:
    solution = Solution()

    # ---- 官方示例 1 ----
    assert solution.threeSum([-1, 0, 1, 2, -1, -4]) == [[-1, -1, 2], [-1, 0, 1]]

    # ---- 官方示例 2：无解 ----
    assert solution.threeSum([0, 1, 1]) == []

    # ---- 官方示例 3：全零恰有一组 ----
    assert solution.threeSum([0, 0, 0]) == [[0, 0, 0]]

    # ---- 全零大数组：初版的超时用例，答案仍只有一组 ----
    assert solution.threeSum([0] * 3000) == [[0, 0, 0]]

    # ---- 最小规模 ----
    assert solution.threeSum([1, 2, 3]) == []

    # ---- 重复值密集：[-2,0,2] 与 [0,0,0] 两组（五个 0 自成一组）----
    assert solution.threeSum([-2] * 5 + [0] * 5 + [2] * 5) == [[-2, 0, 2], [0, 0, 0]]
```

提交前用「哈希 twoSum + set 去重」的正确朴素版做 oracle 随机对照 500 组，与跳重双指针版结果全部一致。

## 总结

1. 排序把问题降维成双指针两数之和；
2. nums[k] > 0 提前剪枝；
3. 外层和找到解后都要跳过重复值。
