> 二分查找将搜索从O(n)降到O(logn)，每次排除一半，是教科书级的查找优化。

寻找两个正序数组的中位数：二分查找的经典应用，折半查找效率高。

题目：

给定两个正序数组 nums1 和 nums2，长度分别为 m 和 n，
请找出这两个正序数组的中位数。
整体运行时间复杂度应为 O(log(m+n))。

示例：

示例 1：
输入：nums1 = [1, 3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1, 2, 3]，中位数是 2
示例 2：
输入：nums1 = [1, 2], nums2 = [3, 4]
输出：2.50000
解释：合并数组 = [1, 2, 3, 4]，中位数是 (2 + 3) / 2 = 2.5

题目翻译：

给定两个正序数组 nums1 和 nums2，长度分别为 m 和 n，
请找出这两个正序数组的中位数。
整体运行时间复杂度应为 O(log(m+n))。

解题思路：

1. 合并数组法（简单但不是最优）：
- 合并两个有序数组
- 直接计算中位数
2. 算法步骤：
- 使用双指针遍历两个数组
- 比较两个数组的元素，较小的被添加到结果中
- 处理较长数组的剩余部分
- 根据合并后数组的长度计算中位数
3. 复杂度分析：
- 时间复杂度: O(m+n)，遍历两个数组
- 空间复杂度: O(1)，只使用常数级别的额外空间

代码：

```cpp
class Solution {
    public:
        double findMediaSortedArrays(int A[], int m, int B[], int n) {
            if (!m && !n) return NULL;
            int tmp = (int)(m+n)/2;
            int result1 = 0;
            int result2 = 0;
            int a = 0, b = 0;

            for (int i = 0; i < tmp; i++) {
                if (a < m && b < n)
                    A[a] < B[b] ? result1 = A[a++] : result1 = B[b++];
                else
                    a < m ? result1 = A[a++] : result1 = B[b++];
            }
            if ((m+n) % 2) {
                if (a < m && b < n)
                    A[a] < B[b] ? result1 = A[a++] : result1 = B[b++];
                else
                    a < m ? result1 = A[a++] : result1 = B[b++];
                return result1;
            } else {
                if (a < m && b < n)
                    result2 = A[a] < B[b] ? A[a++] : B[b++];
                else
                    result2 = a < m ? A[a++] : B[b++];

                return (result2 + result1) / 2.0;
            }
        }
};
```

## 补充：Top 150 分割二分实现

上面合并法需要 `O(m+n)` 时间。Top 150 的新实现改为只在较短数组上二分“左半部分取多少个元素”，把时间复杂度降到 `O(log(min(m, n)))`。

设较短数组贡献 `i` 个元素，另一个数组贡献 `j = (m + n + 1) / 2 - i` 个元素。合法分割需要满足两个左半最大值都不大于对面右半最小值：

- `nums1[i - 1] > nums2[j]`：第一个数组拿多了，切分点左移；
- `nums2[j - 1] > nums1[i]`：第一个数组拿少了，切分点右移；
- 否则分割合法，根据总长度奇偶性计算中位数。

边界位置用 `INT_MIN` 和 `INT_MAX` 作为哨兵，避免单独处理空左半或空右半。

```cpp
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        // 保证 nums1 是较短的那个，二分次数为 O(log(min(m,n)))。
        if (nums1.size() > nums2.size()) {
            return findMedianSortedArrays(nums2, nums1);
        }

        int m = nums1.size();
        int n = nums2.size();
        int half = (m + n + 1) / 2;
        int lo = 0, hi = m;

        while (lo <= hi) {
            int i = (lo + hi) / 2;
            int j = half - i;

            int left1 = (i == 0) ? INT_MIN : nums1[i - 1];
            int right1 = (i == m) ? INT_MAX : nums1[i];
            int left2 = (j == 0) ? INT_MIN : nums2[j - 1];
            int right2 = (j == n) ? INT_MAX : nums2[j];

            if (left1 <= right2 && left2 <= right1) {
                int maxLeft = max(left1, left2);
                int minRight = min(right1, right2);
                if ((m + n) % 2) {
                    return maxLeft;
                }
                return (maxLeft + minRight) / 2.0;
            }
            if (left1 > right2) {
                hi = i - 1;
            } else {
                lo = i + 1;
            }
        }

        return 0.0;
    }
};
```

### 补充复杂度分析

- **时间复杂度**：`O(log(min(m, n)))`，只在较短数组上二分。
- **空间复杂度**：`O(1)`。
