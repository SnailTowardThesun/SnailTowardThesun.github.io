> 异或不进位：0..1023 内的数无论怎么异或，结果仍落在 0..1023。这个 10 位封闭值域让任意路径前缀的异或状态只有 1024 种——正是把万亿条路径折叠成有限状态的关键。

## 题目

LeetCode 3882. Minimum XOR Path in a Grid（网格中的最小异或路径）

Difficulty: **Medium**

给你一个大小为 `m * n` 的二维整数数组 `grid`。你从**左上角**单元格 `(0, 0)` 出发，想要到达**右下角**单元格 `(m - 1, n - 1)`，每一步只能**向右或向下**移动。

一条路径的**代价**是路径上（包括起点和终点）所有单元格值的**按位异或（XOR）**。返回所有路径代价中的**最小值**。

约束：

- `1 <= m == grid.length <= 1000`
- `1 <= n == grid[i].length <= 1000`
- `m * n <= 1000`
- `0 <= grid[i][j] <= 1023`

### 示例

```text
输入：grid = [[1,2],[3,4]]
输出：6
解释：右→下 1⊕2⊕4 = 7；下→右 1⊕3⊕4 = 6，取最小值 6。
```

```text
输入：grid = [[6,7],[5,8]]
输出：9
解释：6⊕7⊕8 = 9；6⊕5⊕8 = 11，最小为 9。
```

```text
输入：grid = [[2,7,5]]
输出：0
解释：单行网格只有一条路径，2⊕7⊕5 = 0。
```

## 解题思路

这道题的提交经历了一场「TLE → MLE → AC」的三连进化，比答案本身更有记录价值。

### 第一版：裸 DFS 枚举所有路径 → 超时

最直觉的写法是 DFS 走遍所有右/下路径，维护全局最小值。问题在于路径总数是组合数 `C(m+n-2, m-1)`：

| 网格 | 路径数 | 实测耗时 |
| ---- | ------ | -------- |
| 10×10 | 48,620 | 0.013s |
| 12×12 | 705,432 | 0.185s |
| 13×13 | 2,704,156 | 0.716s |
| 31×32（约束内最坏） | ≈2.3×10^17 | 换 C++ 也跑不完 |

边长每 +1 耗时约 ×4，指数爆炸。这不是常数优化能救的，必须减少**重复子问题**。

### 关键洞察：把「路径」折叠成「状态」

到达格子 `(x, y)` 之后，后续能得到什么结果，只取决于当前**累计异或值** `pre`，与前面具体怎么走**完全无关**。而 `grid[i][j] <= 1023`（恰好 10 位），异或封闭于此值域——`pre` 最多只有 **1024 种**。

于是状态折叠成三元组 `(x, y, pre)`，用 `vis` 集合记忆化：同一状态的整棵子树只展开一次。状态总数上界 `m * n * 1024 ≈ 10^6`，从天文数字降到毫秒级。

**陷阱**：状态里必须带 `pre`。若只记 `(x, y)`，会把「不同前缀到达同一格」误判为重复而漏解——例如 `[[1,5],[6,3]]`，和最小的路径给 7，真正最优 `1⊕6⊕3 = 4` 恰好在后枚举的那条分支上，剪掉就错了。

### 第二版：元组 set 记忆化 → 超内存

状态数对了，但存法翻车：`set` 里塞 `(x, y, pre)` 三元组，最坏约 10^6 项，实测峰值 **~90MB**（每个三元组 + 集合槽位约 200 字节），超出判题机内存限制。

### 最终版：`ret == 0` 最优性剪枝 → AC

异或值非负，**0 就是可能的最小答案**。一旦某条路径的异或已经等于 0，立即可以停止一切展开——不可能更优了。加上这一行剪枝后通过。

若数据更刁钻（答案普遍非 0），备选方案是把 `vis` 换成位图：每个格子一个 1024 位整数，第 `pre` 位标记该状态是否展开过。语义与元组 set 完全等价，内存从 ~90MB 降到 ~0.2MB，实测 31×32 网格 452KB / 1.7ms。

### 复杂度分析

- 时间复杂度：`O(m * n * 1024)`——每个状态至多展开一次，每次 O(1)
- 空间复杂度：`O(m * n * 1024)`（最坏情况下的记忆化状态存储；`ret == 0` 剪枝后实际远小于此）

## 代码实现

```python
class Solution:
    def minCost(self, grid: list[list[int]]) -> int:
        ret = -1
        # 记忆化：已展开过的状态 (x, y, pre)。pre 必须进 key——不同前缀 XOR 到同一格子，后续并不等价
        vis = set()

        def dfs(x, y, grid: list[list[int]], pre=0) -> None:
            nonlocal ret
            m = len(grid)
            n = len(grid[0])

            state = (x, y, pre)
            if state in vis or ret == 0:  # 同一状态的整棵子树只会被完整走一次
                return
            vis.add(state)

            pre ^= grid[y][x]
            if x == n - 1 and y == m - 1:
                if ret == -1 or pre < ret:
                    ret = pre
                return

            if x < n - 1:
                dfs(x + 1, y, grid, pre)
            if y < m - 1:
                dfs(x, y + 1, grid, pre)

        dfs(0, 0, grid, 0)

        return ret
```

### 代码解析

- `if state in vis or ret == 0: return` 一行两个剪枝：前者是记忆化（同状态子树不重走），后者是最优性剪枝（0 是下界，到手即全局最优，立刻熔断）；
- `pre ^= grid[y][x]` 先把当前格子的值异或进累计值，再判断是否到达终点，保证**起终点都被计入**恰好一次；
- `ret = -1` 作「未设置」哨兵安全：异或结果非负，`-1` 不会与任何真实答案冲突（注意别把哨兵设成 0——答案真能是 0）；
- 递归前用 `x < n - 1` / `y < m - 1` 守卫，天然不会越界调用。

## 测试用例

覆盖官方示例、边界（1×1 / 单列 / 全 0 / 值域上界）、以及专门防「贪心选路」和「只记 (x, y)」两类错误实现的陷阱用例：

```python
def test_solution() -> None:
    solution = Solution()
    # 官方示例
    assert solution.minCost([[1, 2], [3, 4]]) == 6  # 示例 1：下→右 1^3^4=6 优于 右→下 1^2^4=7
    assert solution.minCost([[6, 7], [5, 8]]) == 9  # 示例 2：6^7^8=9 优于 6^5^8=11
    assert solution.minCost([[2, 7, 5]]) == 0  # 示例 3：单行唯一路径 2^7^5=0
    # 边界：1×1 / 单列 / 全 0
    assert solution.minCost([[5]]) == 5  # 起点即终点，路径只含一个格子
    assert solution.minCost([[1023]]) == 1023  # 值域上界，也是可能的最大答案——答案哨兵不能比它小
    assert solution.minCost([[3], [1], [2]]) == 0  # 单列只能一路向下，3^1^2=0
    assert solution.minCost([[0, 0], [0, 0]]) == 0  # 全 0 网格
    # 陷阱：XOR 不是加法，贪心/求和思路会错
    assert solution.minCost([[1, 1, 1]]) == 1  # 奇数个相同值：成对相消后剩一个
    assert solution.minCost([[8, 8], [8, 8]]) == 8  # 路径长 m+n-1=3 为奇数，三个 8 抵不成 0
    assert solution.minCost([[1, 5], [6, 3]]) == 4  # 和最小的路径 1,5,3 给 7；真正最优是 1^6^3=4
    assert solution.minCost([[1023, 1], [2, 1023]]) == 1  # 两个 1023 相互抵消，答案与大值无关
    # 多路径组合（期望值经全路径枚举暴力验证）
    assert solution.minCost([[7, 1, 4], [2, 6, 3], [5, 0, 2]]) == 1  # 3×3，含 0
    assert solution.minCost(
        [[3, 10, 14, 6, 6], [12, 14, 9, 14, 8], [14, 8, 8, 8, 9], [1, 7, 8, 14, 8], [3, 13, 15, 8, 10]]
    ) == 2  # 5×5，最优 XOR 恰为 2
```

## 总结

- 路径枚举是组合级爆炸（约束内最坏 C(61,30)≈2.3×10^17 条），但「格子 × 异或值」只有约 10^6 个状态——值域 10 位这条约束就是出题人留的折叠入口；
- 记忆化状态必须含累计异或值 `pre`，只记坐标会漏解；最小值哨兵选 `-1` 而不是 `0`，因为 0 是合法答案；
- `ret == 0` 最优性剪枝一行熔断全场：非负目标遇到下界即停；追求极致内存时可换位图存储（~0.2MB）。
