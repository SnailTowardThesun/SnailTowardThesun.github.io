> "深度即权重"的思想同样出现在文件系统树形统计中，2 的幂让嵌套结构量化变得异常简洁。

## 题目

LeetCode 856. Score of Parentheses（括号的分数）

Difficulty: **Medium**

给定一个平衡括号字符串 `s`，按如下规则计算并返回它的得分：

- `()` 得 1 分；
- `AB` 得 `A + B` 分，其中 `A` 和 `B` 是平衡括号字符串；
- `(A)` 得 `2 * A` 分，其中 `A` 是平衡括号字符串。

### 示例

```
输入：s = "()"
输出：1

输入：s = "(())"
输出：2

输入：s = "()()"
输出：2

输入：s = "(()(()))"
输出：6
```

## 解题思路

### 深度计数法

把 `(A)` 展开来看：`(A) = 2 * A`，而 `((A)) = 4 * A`……嵌套 `d` 层的 `()` 最终贡献 `2^d` 分。整个字符串的分数其实是**所有最内层 `()` 的加权和**，权重由各自的嵌套深度决定。

于是只需一次遍历：

1. 维护 `depth` 表示当前嵌套深度；
2. 遇到 `'('` 时深度加一；
3. 遇到 `')'` 时深度减一；若**前一个字符是 `'('`**（即刚好遇到一对最内层 `()`），向结果累加 `1 << depth`。

以 `"(()(()))"` 为例：

```
( ( ) ( ( ) ) )
  ↑         ↑
深度2的()   深度2的()
贡献 2^2=4  贡献 2^2=2 ... 
实际: 4 + 2 = 6 ✓
```

第二对 `()` 在 `))` 之前深度为 2，贡献 `2^2 = 4`；内层 `(()(()))` 中的 `()` 深度也是 2，贡献 4？注意第二对的深度：`(`(1) `(`(2) `)`(回1) —— 内层对深度为 2，贡献 4；最外层再包一层。实际累加：外层第一对内嵌 `()` 深度 2 贡献 4，内层 `()` 深度 2 贡献 2，`4 + 2 = 6`。

### 复杂度分析

- **时间复杂度**：O(n)，每个字符处理一次。
- **空间复杂度**：O(1)，只使用常数额外空间。

## 代码实现

```cpp
class Solution {
   public:
    int scoreOfParentheses(string s) {
        int ret = 0;

        if (s.empty() || s.size() % 2 != 0) {
            return ret;
        }

        int depth = 0;
        for (auto i = 0; i < s.size(); ++i) {
            if (s[i] == '(') {
                depth++;
            } else {
                depth--;
                if (s.at(i - 1) == '(') {
                    ret += 1 << depth;
                }
            }
        }

        return ret;
    }
};
```

### 代码解析

- **识别最内层 `()`**：`s[i] == ')'` 且 `s[i-1] == '('` 就是核心判断，说明这是一对没有再嵌套内容的括号。
- **先减再取权重**：遇到 `')'` 先 `depth--`，此时的 `depth` 恰好是这对 `()` 外层的深度，`1 << depth` 即它的贡献。
- **健壮性检查**：函数开头对空串和奇数长度做了防御性返回（题目保证输入平衡，此处是额外保护）。

## 测试用例

```cpp
TEST(Daily, 856) {
    Solution s;
    // 最简单
    EXPECT_EQ(s.scoreOfParentheses("()"), 1);
    // 一层嵌套翻倍
    EXPECT_EQ(s.scoreOfParentheses("(())"), 2);
    // 并列相加
    EXPECT_EQ(s.scoreOfParentheses("()()"), 2);
    // 嵌套加并列
    EXPECT_EQ(s.scoreOfParentheses("(()(()))"), 6);
}
```

## 总结

1. 括号分数 = 所有最内层 `()` 的 `2^深度` 之和；
2. `depth` 计数 + `前一个字符是否 '('` 识别最内层对；
3. 先减深度再取权重是关键顺序，O(n) 时间、O(1) 空间。
