> 一个节点最多贡献数字 9，两位数字连同上一位的进位相加，最大和为 19。因此向高位传递的进位只需保存 0 或 1。

## 题目

两条非空单链表分别表示两个非负整数，每个节点存一位数字，个位在链表头。求两个整数的和，并以相同的顺序返回结果链表。每条输入链表有 1 到 100 个节点，节点值为 0 到 9。除数字 0 本身以外，最高位均非零。[LeetCode 2. Add Two Numbers（中等）](https://leetcode.com/problems/add-two-numbers/description/)

### 示例

| 第一条链表 | 第二条链表 | 结果链表 |
| --- | --- | --- |
| `[2,4,3]` | `[5,6,4]` | `[7,0,8]` |
| `[0]` | `[0]` | `[0]` |
| `[9,9,9,9,9,9,9]` | `[9,9,9,9]` | `[8,9,9,9,0,0,0,1]` |

## 解题思路

两数相加：小时候用算盘拨珠子，现在用链表模拟——进位就像小时候的十进制进位一样自然。

两个头节点对应个位，沿 `next` 前进一步就进入更高一位。设本位的两个数字与进位之和为 `s`，把 `s % 10` 追加到结果链表，并将 `s // 10` 留给下一位。较短链表走完后，它在后续各位贡献 0。

以第一组示例的 342 + 465 为例，个位 2 + 5 得 7。十位 4 + 6 得 10，写 0 并进 1。百位 3 + 4 再加进位得 8。结果从头读作 `[7,0,8]`，表示 807。对于 99 + 1，两个输入都已走完时仍有进位 1，追加这个节点才能得到 `[0,0,1]`。

### 复杂度分析

设两条输入链表的长度为 `m` 和 `n`。逐位相加耗时 `O(max(m,n))`，指针和进位占用 `O(1)` 额外空间。输出链表最多有 `max(m,n) + 1` 个节点。

## 代码实现

三种写法都从哑节点开始构造结果。C++ 和 Python 分别处理两条链表都有数字的阶段和剩余高位，Rust 在同一个循环中处理这两种情况。

class Solution {
   public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        if (l1 == NULL || l2 == NULL) return l1 == NULL ? l1 : l2;

        ListNode result(0);
        ListNode* pResult = &result;
        ListNode* p1 = l1;
        ListNode* p2 = l2;
        int isBiggerThenTen = 0;
        while (p1 != NULL && p2 != NULL) {
            int tmp = 0;
            tmp = p1->val + p2->val + isBiggerThenTen;
            ListNode* tmpNode = new ListNode((tmp) % 10);
            pResult->next = tmpNode;
            pResult = pResult->next;
            tmp >= 10 ? isBiggerThenTen = 1 : isBiggerThenTen = 0;
            p1 = p1->next;
            p2 = p2->next;
        }
        while (p1 != NULL || p2 != NULL || isBiggerThenTen != 0) {
            int tmp = 0;
            ListNode* tmpNode = NULL;
            if (p1 != NULL || p2 != NULL) {
                if (p1 == NULL) {
                    tmp = p2->val + isBiggerThenTen;
                    tmpNode = new ListNode(tmp % 10);
                    tmp >= 10 ? isBiggerThenTen = 1 : isBiggerThenTen = 0;
                    p2 = p2->next;
                } else {
                    tmp = p1->val + isBiggerThenTen;
                    tmpNode = new ListNode(tmp % 10);
                    tmp >= 10 ? isBiggerThenTen = 1 : isBiggerThenTen = 0;
                    p1 = p1->next;
                }
            } else {
                tmpNode = new ListNode(isBiggerThenTen);
                isBiggerThenTen = 0;
            }
            pResult->next = tmpNode;
            pResult = pResult->next;
        }
        return result.next;
    }
};

class Solution:
    def addTwoNumbers(self, l1: ListNode | None, l2: ListNode | None) -> ListNode | None:
        if l1 is None:
            return l2
        if l2 is None:
            return l1

        root = ListNode(0)
        carry = 0

        cur, cur_1, cur_2 = root, l1, l2
        while cur_1 is not None and cur_2 is not None:
            val = cur_1.val + cur_2.val + carry
            if val > 9:
                val = val - 10
                carry = 1
            else:
                carry = 0

            n = ListNode(val)
            cur.next = n
            cur = cur.next

            cur_1 = cur_1.next
            cur_2 = cur_2.next

        while cur_1 is not None:
            val = cur_1.val + carry
            if val > 9:
                val = val - 10
                carry = 1
            else:
                carry = 0
            n = ListNode(val)
            cur.next = n
            cur = cur.next
            cur_1 = cur_1.next

        while cur_2 is not None:
            val = cur_2.val + carry
            if val > 9:
                val = val - 10
                carry = 1
            else:
                carry = 0
            n = ListNode(val)
            cur.next = n
            cur = cur.next
            cur_2 = cur_2.next

        if carry > 0:
            cur.next = ListNode(carry)

        return root.next

{% highlight rust %}
fn add_two_numbers(l1: Option<Box<ListNode>>, l2: Option<Box<ListNode>>) -> Option<Box<ListNode>> {
    let mut ret = Some(Box::new(ListNode::new(0)));
    let (mut p1, mut p2, mut carry) = (l1, l2, 0);
    let mut pos = ret.as_mut();
    while p1.is_some() || p2.is_some() {
        let mut sum = carry;

        if let Some(v) = p1 {
            sum += v.val;
            p1 = v.next;
        }

        if let Some(v) = p2 {
            sum += v.val;
            p2 = v.next;
        }

        if sum >= 10 {
            carry = 1;
            sum = sum - 10;
        } else {
            carry = 0;
        }

        let v = pos.unwrap();
        v.next = Some(Box::new(ListNode::new(sum)));
        pos = v.next.as_mut();
    }

    if carry > 0 {
        let v = pos.unwrap();
        v.next = Some(Box::new(ListNode::new(1)));
    }

    return ret.unwrap().next;
}

### 代码解析

尾指针始终指向已经写好的最高位，下一次生成的节点直接接在它后面。**C++** 在栈上创建哑节点，返回其后继指针。**Python** 将 `carry` 传入处理剩余高位的循环，所以即使一侧已经耗尽，另一侧的一串 9 仍能逐位进位。**Rust** 通过 `Option<Box<ListNode>>` 依次取出两个输入节点，用 `pos` 记录结果尾部。

## 测试用例

下面两次调用分别覆盖进位穿过整个剩余链表，以及进位在中途消失。

```python
from leetcode_common import build_list, to_list

solution = Solution()
assert to_list(solution.addTwoNumbers(build_list([1]), build_list([9, 9]))) == [0, 0, 1]
assert to_list(solution.addTwoNumbers(build_list([9, 0, 4]), build_list([1]))) == [0, 1, 4]
```

## 总结

链表顺序与竖式加法的计算顺序一致，每轮写入一位并向下一位传递进位即可。最后的进位决定结果是否需要多一个节点。
