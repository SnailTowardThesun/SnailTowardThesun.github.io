> 在三数之和外再套一层循环：固定两个数，双指针找另外两个。kSum 系列是同一套模板的递归展开。

## 题目

LeetCode 18. 4Sum（四数之和）

Difficulty: **Medium**

给定整数数组 nums 和目标值 target，找出所有不重复的四元组使其和等于 target。

### 示例

```
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]

输入：nums = [2,2,2,2], target = 8
输出：[[2,2,2,2]]
```

## 解题思路

### 排序 + 两层固定 + 双指针

1. 排序后外层双重循环固定 nums[i]、nums[j]。
2. 在 `[j+1, n-1]` 上双指针找和为 `target - nums[i] - nums[j]` 的两个数。
3. 源文件用 set 收集结果天然去重；也可以像三数之和那样手动跳过重复值。

### 复杂度分析

- **时间复杂度**：O(n³)。
- **空间复杂度**：O(k)，k 为解的数量（set 存储）。

## 代码实现

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        set<vector<int>> res;
        sort(nums.begin(), nums.end());
        for (int i = 0; i < int(nums.size() - 3); ++i) {
            for (int j = i + 1; j < int(nums.size() - 2); ++j) {
                int left = j + 1, right = nums.size() - 1;
                while (left < right) {
                    int sum = nums[i] + nums[j] + nums[left] + nums[right];
                    if (sum == target) {
                        res.insert({nums[i], nums[j], nums[left], nums[right]});
                        ++left; --right;
                    } else if (sum < target) ++left;
                    else --right;
                }
            }
        }
        return vector<vector<int>>(res.begin(), res.end());
    }
};
```

### 代码解析

- 循环上界用 `size - 3`、`size - 2` 保证后面留够指针位置，int 强转避免无符号减法下溢。

## 测试用例

```cpp
TEST(Daily, 18) {
    Solution s;
    vector<int> nums1 = {1, 0, -1, 0, -2, 2};
    EXPECT_EQ(s.fourSum(nums1, 0).size(), 3);
    vector<int> nums2 = {2, 2, 2, 2};
    auto r2 = s.fourSum(nums2, 8);
    EXPECT_EQ(r2.size(), 1);
}
```

## 总结

1. kSum 就是固定 k-2 个数后双指针；
2. 排序 + set 去重是最省心的写法；
3. 注意无符号整数做循环边界时下溢问题。
