> 1956 年 Dijkstra 在阿姆斯特丹一家咖啡馆里，为回答「从鹿特丹到格罗宁根怎么走最快」用二十分钟设计了这个算法；今天手机导航和路由器里的 OSPF 协议，跑的仍然是它。

# 算法系列--Dijkstra：从起点一圈圈荡开的最短路

## 为什么需要 Dijkstra

给定一张边权非负的图和一个起点 s，求 s 到其他每个点的最小总边权——这就是**单源最短路**（Single-Source Shortest Path）。它是最古老的图论问题之一，也是工程里出场率最高的算法之一：

- **地图导航**：起点到终点的最快/最短路线，边权是时间或里程；
- **网络路由**：OSPF、IS-IS 协议里，每台路由器以自己为源跑一遍 Dijkstra 得到最短路径树，据此决定下一跳；
- **换乘与中转**：地铁 App 算最少时间，机票平台算最低票价，都可以建模成带权图；
- **物流与机器人**：代价换成距离、能耗或风险，模型不变；
- **游戏与芯片**：网格寻路、布线时的底座算法（实际产品常在其上加启发式，即 A*）。

为什么不用更简单的办法？三个直觉方案都不行：

1. **枚举所有路径**：路径数是组合级爆炸，n 个点的图就能有天文数字条路径；
2. **BFS 按层扩展**：只对无权图（或所有边等权）成立。BFS 保证「跳数少」，不保证「权和小」——一条权 1 的远路可能优于一条权 100 的近路；
3. **每步贪心选最便宜的边**：局部最优不是全局最优，一条眼前的大边可能换来回程无数条小边。

1956 年，Edsger W. Dijkstra 为了给新计算机 ARMAC 找一个不涉及排序的演示问题，在咖啡馆里把它设计了出來（1959 年正式发表，没有申请专利）。思路是把「贪心」用在正确的位置上：不贪边，贪**点**——每次敲定离起点最近的那个未确定点。

## 核心思想

全部推导只靠两个动作。

**松弛（relax）**：对边 `u→v` 权 `w`，若 `dist[u] + w < dist[v]`，就把 `dist[v]` 更新为 `dist[u] + w`——「绕经 u 到 v 更近，那就改走 u」。`dist` 是「目前已知的最短距离上界」，只会被压小，不会变大。

**敲定（settle）**：维护两个集合，已敲定 S 与未敲定 Q。每轮从 Q 里挑 `dist` 最小的点 u，宣布 `dist[u]` 就是最终答案、移入 S，再用 u 的所有出边做一轮松弛。重复直到 Q 空。

**为什么敢敲定**——非负权 + 反证。设敲定 u 时存在更短路 P: s→…→u，其总权小于 `dist[u]`。P 必有一条边 `x→y` 跨过集合边界（x 已敲定，y 未敲定）。x 敲定时它的出边都松弛过，所以 `dist[y] ≤ dist[x] + w(x,y)`；而 P 的前缀不短于 `dist[x]`、P 的剩余部分（含 `x→y` 及之后）全部非负，于是 `dist[y] ≤ w(P)`。又因为敲定 u 时 u 是 Q 中最小者，`dist[u] ≤ dist[y] ≤ w(P) < dist[u]`，矛盾。∎

注意证明的最后一步用到了「P 的剩余部分非负」——这就是 Dijkstra 不能碰负权边的根源，后面给反例。

直觉图像：往起点丢一颗石子，水波一圈圈荡开；每一圈就是「当前最近的一批点被敲定」，荡到的顺序恰好是从近到远。

### 手算一遍

四点有向图，边：`0→1 (4)`、`0→2 (1)`、`2→1 (2)`、`1→3 (5)`、`2→3 (8)`：

```text
        4
    0 ───→ 1
    │    ↗  │
    1  2    5
    │ ↗     │
    ↓/      ↓
    2 ───→ 3
        8
```

| 轮次 | 出堆 (d, u) | 动作 | dist |
|---|---|---|---|
| 初始 | — | 源点 0 入堆 | `[0, ∞, ∞, ∞]` |
| 1 | (0, 0) | 松弛 0→1 得 4；0→2 得 1 | `[0, 4, 1, ∞]` |
| 2 | (1, 2) | 松弛 2→1 得 1+2=3，压掉 4；2→3 得 9 | `[0, 3, 1, 9]` |
| 3 | (3, 1) | 松弛 1→3 得 3+5=8，压掉 9 | `[0, 3, 1, 8]` |
| 4 | (4, 1) | 4 > dist[1]=3，过期条目，跳过 | 不变 |
| 5 | (8, 3) | 敲定终点 3，结束 | `[0, 3, 1, 8]` |

三个值得驻足的瞬间：

- **第 2 轮**：点 2 先于点 1 敲定。1 离源点的「跳数」更少，但加权距离更远——这正是 Dijkstra 与 BFS 的本质区别：队列按距离排序，不按层数；
- **第 3 轮**：dist[3] 从 9 被压到 8。最短路 `0→2→1→3` 不是「每步都最便宜」的路（第一步走 1 才 4，但它后面只能 4+5=9）——贪心选边不成立、贪心敲定成立的原因；
- **第 4 轮**：堆里同时躺着 (4,1) 和 (3,1)，先弹出的必是更小的；后到的旧条目出堆时发现 4 > dist[1]，直接丢弃——这就是下文的「惰性删除」。

## Python 实现

约定：n 个节点编号 `0..n-1`，`edges` 里的 `(u, v, w)` 是权 `w ≥ 0` 的有向边，返回源点到各点的最短路长（不可达为 `inf`）：

```python
import heapq


def dijkstra(n: int, edges: list[tuple[int, int, int]], src: int) -> list[float]:
    """堆优化 Dijkstra：非负边权，返回 src 到各点的最短路长，不可达为 inf。"""
    adj: list[list[tuple[int, int]]] = [[] for _ in range(n)]
    for u, v, w in edges:
        adj[u].append((v, w))

    INF = float("inf")
    dist = [INF] * n
    dist[src] = 0
    heap = [(0, src)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]:  # 惰性删除：早已被更小值覆盖的过期条目
            continue
        for v, w in adj[u]:
            if d + w < dist[v]:  # 松弛：绕经 u 到 v 更近就更新
                dist[v] = d + w
                heapq.heappush(heap, (d + w, v))
    return dist
```

无向图把每条边 `adj[u].append((v, w))`、`adj[v].append((u, w))` 各加一次即可；多个起点（多源最短路）把所有源点都以代价 0 入堆，等价于接一个零边「超级源点」。

### 分层图：把约束写进状态——LeetCode 3970

今天的每日一题 [3970. 最多 K 个连续相同字符的最短路径](https://leetcode.cn/problems/shortest-path-with-at-most-k-consecutive-identical-characters/description/)：有向带权图中从 0 走到 n-1，路径上节点标签拼接后**连续相同字符不得超过 k**，求最小总边权。

只按节点记 `dist` 是错的：**到达同一个点的两条路，尾部连续段长不同，后面能走的边就不同**。把状态从「节点」扩成「(节点, 尾部连续段长)」，相当于把图复制成 k 层，算法本体一字不改：

```python
class Solution:
    def shortestPath(self, n: int, edges: list[list[int]], labels: str, k: int) -> int:
        adj = [[] for _ in range(n)]
        for u, v, w in edges:
            adj[u].append((v, w))

        INF = float("inf")
        # dist[v][r]：到达 v 且尾部连续段长恰为 r 的最小总边权
        dist = [[INF] * (k + 1) for _ in range(n)]
        dist[0][1] = 0
        heap = [(0, 0, 1)]
        while heap:
            d, u, r = heapq.heappop(heap)
            if d > dist[u][r]:
                continue
            if u == n - 1:
                return d  # 终点首次出堆即最小
            for v, w in adj[u]:
                nr = r + 1 if labels[v] == labels[u] else 1  # 同字符接长，异字符重开
                if nr > k:
                    continue  # 会凑出 k+1 个连续相同字符，禁止
                if d + w < dist[v][nr]:
                    dist[v][nr] = d + w
                    heapq.heappush(heap, (d + w, v, nr))
        return -1
```

用一张小图看「为什么必须分层」。`labels = "aaba"`，k = 2，边 `0→1 (1)`、`0→2 (5)`、`2→1 (1)`、`1→3 (1)`：

```text
0 ──1──→ 1 ──1──→ 3
│        ↑
5        1
│        │
└──→ 2 ──┘

普通最短路：0→1→3，权 2，标签 "aaa"——3 个连续 'a'，超过 k=2，非法
分层图答案：0→2→1→3，权 7，标签 "abaa"——最长段 "aa" 恰为 2，合法
```

若只按节点取最小，点 1 会被「代价 1、段长 2」的状态独占，1→3 这条边被误判为走得通，得出错误答案 2；带上段长后，(1, 段长 2) 撞墙、(1, 段长 1) 从绕路的 (2, 段长 1) 处接棒，才能正确到达终点。**「油量、步数、时间、连续段长」这类附加约束，套路都是同一个：约束入状态，图变 k 层，Dijkstra 原样跑。**

## 关键实现解析

### 堆里放 (d, u) 而不是 (u, d)

`heapq` 按元组首元素比较，距离在前才是「每次弹出当前最近」。距离相同再比节点号，纯整数比较永不抛错。反过来放会按节点号出堆，整个算法退化成乱序遍历。

### 惰性删除

Python 的 `heapq` 没有 decrease-key 操作。松弛成功时不删旧条目、只 push 新值，堆里于是同时存在同一个点的多个版本；弹出时用 `d > dist[u]` 识别过期残影，跳过即可。堆最大 O(E)，总代价 O(E log E)，且 E < V² 时 log E 与 log V 同阶。

### 出堆才敲定，入堆不算

入堆时的 d 只是当时的上界，之后还可能被更小值覆盖；只有出堆、且未过期的那一刻，`dist[u]` 才成为最终答案。所以「到达终点的判断」「对答案的收集」必须写在出堆之后——写在入堆（松弛）处是高频 bug，会把一个尚不是最优的值当答案返回。`dist` 数组本身兼作 visited：`d > dist[u]` 已涵盖「第一次出堆还是重复出堆」，不需要单独的 visited 集合。

### 负权边是红线

反例：边 `0→1 (1)`、`0→2 (5)`、`2→1 (-10)`。真实最短路到 1 是 `5 + (-10) = -5`，但 Dijkstra 出堆顺序是 0、1、2——点 1 以 1 被敲定，标准实现不会回头修改已敲定的点，答案停在 1，错了。即便实现允许回炉重推，最坏复杂度也不再是 O((V+E)logV)。负权图请换 Bellman-Ford（还能判负环）或 SPFA；「全源 + 稀疏负权」可用 Johnson 重赋权把边权调非负后再跑 Dijkstra。

### 稠密图换朴素 O(V²) 版

邻接矩阵 + 每轮线性扫出未敲定的最小点，复杂度 O(V²)，代码更短。当 E 接近 V²（稠密）或 V 很小时，它比堆版的 O(E log V) 更快——E = V² 时堆版要 V²·log V，朴素版只有 V²。经验法则：稀疏图用堆，稠密图或小图用朴素。

### 隐式图不用先建图

网格图、状态搜索题里往往没有显式的 edges，把「出堆一个点时现场生成它的邻居」当作邻接表即可（如 2577 的网格、3970 的 (点, 段长) 状态），图只存在于转移函数里。

## 使用示例

```python
edges = [(0, 1, 4), (0, 2, 1), (2, 1, 2), (1, 3, 5), (2, 3, 8)]

print(dijkstra(4, edges, 0))  # [0, 3, 1, 8]，与手算表格一致

# LeetCode 3970：约束入状态的分层版
s = Solution()
print(s.shortestPath(3, [[0, 1, 1], [1, 2, 1], [0, 2, 3]], "aab", 1))  # 3：便宜路径 "aab" 被封，绕直连
print(s.shortestPath(3, [[0, 1, 1], [1, 2, 1], [0, 2, 3]], "aab", 2))  # 2：k 放宽，便宜路径恢复合法
print(s.shortestPath(4, [[0, 1, 1], [0, 2, 5], [2, 1, 1], [1, 3, 1]], "aaba", 2))  # 7：贵的状态反而走得通
```

## 测试设计

3970 的测试（完整版在题解仓库 `python/questions/3970.py`）重点钉住四件事：官方示例、起点即终点与不可达两个边界、**同一节点两种到达状态的取舍**、约束放宽后答案的翻转。

```python
def test_solution() -> None:
    solution = Solution()
    # 官方示例：便宜路径被封 / 放宽 / 无解
    assert solution.shortestPath(3, [[0, 1, 1], [1, 2, 1], [0, 2, 3]], "aab", 1) == 3
    assert solution.shortestPath(3, [[0, 1, 1], [1, 2, 1], [0, 2, 3]], "aab", 2) == 2
    assert solution.shortestPath(3, [[0, 1, 1], [1, 2, 1]], "aaa", 2) == -1
    # 边界：起点即终点；无边不可达
    assert solution.shortestPath(1, [], "a", 1) == 0
    assert solution.shortestPath(2, [], "ab", 5) == -1
    # 核心：便宜的到达 (1, 段长2) 撞墙，绕路的 (1, 段长1) 接棒；k 放宽后立刻翻转回 2
    assert solution.shortestPath(4, [[0, 1, 1], [0, 2, 5], [2, 1, 1], [1, 3, 1]], "aaba", 2) == 7
    assert solution.shortestPath(4, [[0, 1, 1], [0, 2, 5], [2, 1, 1], [1, 3, 1]], "aaba", 3) == 2
    # 重边取优
    assert solution.shortestPath(2, [[0, 1, 7], [0, 1, 3]], "ab", 1) == 3
```

「7 对 2」这组是分层图正确性的试金石：只按节点记 dist 的错误实现会算出 2，恰好被它逮住。

## 变体与延伸

- **分层图 / 扩展状态**：剩余油量、已用步数、剩余时间、连续段长——约束入状态，图复制成若干层，层间按约束转移。787（K 站中转）、1928（限时最小花费）、3970（本题）全是这个模式；
- **最小化「路径上最大边」**：1631、778。松弛改成 `max(dist[u], w)`，正确性同样依赖非负权；
- **次短路**：2045。每个点同时维护最短和次短两个值，松弛时两本账一起记；
- **路径计数与还原**：1976 在松弛时同步累加方案数；3123 用前驱数组还原最短路树再找临界边；
- **A\***：有下界性质的启发式（曼哈顿距离等）时，堆按 `f = g + h` 排序，朝终点定向扩展——导航软件实际跑的多是 A* 与双向 Dijkstra。

## 复杂度与适用边界

设节点数 V、边数 E：

- 堆优化版时间 O((V + E) log V)（惰性删除为 O(E log E)，稀疏图下同阶），空间 O(V + E)；
- 朴素版时间 O(V²)、空间 O(V²)（邻接矩阵），稠密图更优。

一族最短路算法的分工：

| | BFS | 0-1 BFS | Dijkstra | Bellman-Ford | Floyd |
|---|---|---|---|---|---|
| 边权 | 无权/等权 | 只有 0 和 1 | 非负 | 任意，可判负环 | 任意 |
| 解决的问题 | 单源 | 单源 | 单源 | 单源 | 所有顶点对 |
| 复杂度 | O(V+E) | O(V+E) | O((V+E)logV) | O(VE) | O(V³) |

选型口诀：无权用 BFS（更快更简单），权只有 0/1 用双端队列的 0-1 BFS，非负权用 Dijkstra，有负权用 Bellman-Ford/SPFA，要所有点对且 V 小用 Floyd。Dijkstra 的位置很明确：**非负权 + 单源，它就是默认解**；题面给出 `1 ≤ wi` 这种全正权约束时，基本就是在明示 Dijkstra。

分层图还要多算一笔状态维度的账：3970 的状态数是 n×k（5×10⁴ × 50 = 2.5×10⁶），复杂度变成 O(E·k·log(n·k))。扩展状态前先估算状态总数是否在时限内，是这类题的第一步。

## 总结

- Dijkstra = 松弛 + 贪心敲定：每轮从未确定集合里取 `dist` 最小的点宣布为最终答案，再用它的出边压别人的上界。非负权保证「出堆即最短」，这是它能贪心的全部前提；
- 三个高频坑：终点判断要写在出堆之后（入堆值只是上界）、惰性删除的过期条目要跳过、负权边必须换算法；
- 带约束的最短路（油量/步数/时间/连续段长）通用套路是分层图：约束并入状态、图复制成多层、算法本体不变——今天的 3970 正是这个模式的最新一次出场。
