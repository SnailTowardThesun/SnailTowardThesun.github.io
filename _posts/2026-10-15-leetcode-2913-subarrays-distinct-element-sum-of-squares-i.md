## 题目

LeetCode 2913. Subarrays Distinct Element Sum of Squares I（子数组不同元素数目的平方和 I）

Difficulty: **Easy**

给你一个下标从 **0** 开始的整数数组 `nums`。

定义 `nums` 一个子数组的**不同计数**值如下：

- 令 `nums[i..j]` 表示 `nums` 中所有下标在 `i` 到 `j` 范围内的元素构成的子数组（满足 `0 <= i <= j < nums.length`），那么我们称子数组 `nums[i..j]` 中**不同值的数目**为 `nums[i..j]` 的不同计数。

请你返回 `nums` 中**所有**子数组的不同计数的**平方和**。

### 示例

```
输入：nums = [1,2,1]
输出：15
解释：六个子数组的不同计数分别为 1、1、1、2、2、2，
     平方和 = 1 + 1 + 1 + 4 + 4 + 4 = 15

输入：nums = [2,2]
输出：3
解释：三个子数组 [2]、[2]、[2,2] 的不同计数均为 1，平方和 = 3
```

## 解题思路

数据规模很小（`n <= 100`），直接暴力枚举所有子数组即可，核心是**固定左端点、向右扩展右端点**的枚举顺序，让"去重集合"可以增量维护。

1. 外层枚举子数组**左端点** `i`；
2. 内层从 `i` 开始向右扩展**右端点** `j`，用 `unordered_set` 维护当前子数组的不同值集合，每加入一个元素均摊 O(1) 更新；
3. 每扩展一步，把当前集合大小的平方累加到答案。

以 `nums = [1,2,1]` 为例，手算如下：

```
i = 0: j=0 {1}       → 1² = 1
       j=1 {1,2}     → 2² = 4
       j=2 {1,2}     → 2² = 4
i = 1: j=1 {2}       → 1² = 1
       j=2 {2,1}     → 2² = 4
i = 2: j=2 {1}       → 1² = 1
结果 = 1 + 4 + 4 + 1 + 4 + 1 = 15
```

**易错点**：内层循环必须从 `j = i` 开始，而不是从 `0` 开始。若从 0 开始，`j < i` 的"子数组"不合法，且集合每次都从下标 0 重新累加，等于把同一段重复统计——比如 `[1,2]` 会算出 10 而不是正确的 6。

### 复杂度分析

- **时间复杂度**：O(n^2)，枚举全部子数组，每个元素的哈希插入均摊 O(1)。
- **空间复杂度**：O(n)，哈希集合最多存 n 个不同元素。

## 代码实现

```cpp
class Solution {
public:
    int sumCounts(vector<int>& nums) {
        int ret = 0;
        int n = nums.size();

        for (int i = 0; i < n; i++) {
            unordered_set<int> tmp;
            for (int j = i; j < n; j++) {
                tmp.insert(nums[j]);
                ret += tmp.size() * tmp.size();
            }
        }

        return ret;
    }
};
```

### 代码解析

- **枚举顺序**：先固定左端点 `i` 再扩展右端点 `j`，保证内层每前进一步只新增一个元素，去重集合无需回退，这是所有"子数组 + 增量维护"题目的通用套路；
- **`unordered_set` 去重**：`tmp.size()` 恒等于当前子数组的不同值数目，插入重复元素不改变大小；
- **溢出检查**：`n = 100` 且元素全不同时答案上界约 8.7 * 10^6，`int` 完全够用，无需 `long long`。

## 测试用例

```cpp
TEST(Daily, 2913) {
    Solution s;

    // 官方示例 1：六个子数组的不同计数 1、1、1、2、2、2
    vector<int> nums1 = {1, 2, 1};
    EXPECT_EQ(s.sumCounts(nums1), 15);

    // 官方示例 2：三个子数组的不同计数均为 1
    vector<int> nums2 = {2, 2};
    EXPECT_EQ(s.sumCounts(nums2), 3);

    // 手算用例：[1,2] 的子数组 [1]、[2]、[1,2] → 1 + 1 + 4 = 6
    vector<int> nums3 = {1, 2};
    EXPECT_EQ(s.sumCounts(nums3), 6);

    // 边界：单元素数组
    vector<int> nums4 = {7};
    EXPECT_EQ(s.sumCounts(nums4), 1);
}
```

## 总结

1. 固定左端点、扩展右端点的枚举顺序让去重集合可以增量维护，是子数组计数类问题的基础套路；
2. 内层必须从 `j = i` 开始，从 0 开始会重复统计非法子数组；
3. `n <= 100` 时 O(n^2) 暴力足矣，加强版 2914 才需要贡献法优化。
